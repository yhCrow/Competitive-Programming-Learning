33.1 ISAP	 算法
Distance	labels,	relabel,	gap.
IDEA ISAP (Improved Shortest Augmenting Path) keeps a distance label d[v] = distance from v to the sink in the
residual graph, computed once by BFS from t. It only pushes along edges with d[u] = d[v] + 1; when u has
no such edge, it relabels d[u] to 1 + the smallest label among its usable neighbours, instead of rebuilding
all levels as Dinic does.
KEY POINT Gap	optimisation: keep cnt[k] = number of vertices with label k. If relabelling empties some cnt[k], no
path from s to t can exist any more, so stop. With current-arc and gap, ISAP is usually as fast as or faster
than Dinic, and needs only one BFS.

13 long long dfs(int u, long long f) {
14     if (u == t) return f;
15     long long used = 0;
16     for (int &k = cur[u]; k < int(g[u].size()); k++) {
17         int id = g[u][k]; Edge &x = e[id];
18         if (x.cap > 0 && dist_[u] == dist_[x.to] + 1) {
19             long long got = dfs(x.to, min(f - used, x.cap));
20             x.cap -= got; e[id ^ 1].cap += got; used += got;
21             if (used == f) return used;
22         }
23     }
24     // no admissible edge left: relabel u
25     if (--cnt[dist_[u]] == 0) dist_[s] = n;      // gap: s can no longer reach t
26     dist_[u]++; cnt[dist_[u]]++;
27     cur[u] = 0;
28     return used;
29 }

33.2 混合图的欧拉回路
Orient,	parity,	flow	to	fix.
IDEA Euler	circuit	in	a	mixed	graph ( 混合图的欧拉回路 ): some edges are directed, others may be oriented
either way. Orient the undirected edges arbitrarily and compute xv = out(v) − in(v). Every xv must be even
(flipping an edge changes it by 2). Then decide which undirected edges to flip with a flow: flipping u → v
moves 2 from xu to xv.
KEY POINT Build: each undirected edge oriented u → v gives a flow edge u → v of capacity 1 (flipping it); s → v with
capacity xv/2 for xv > 0, v → t with capacity −xv/2 for xv < 0. A circuit exists iff the flow saturates all
source edges (and the edges are connected). Bridges (P3511) binary-searches a limit and runs this test.

9 bool bfs(int n) {
10     fill(level, level + n, -1); queue<int> q; level[S] = 0; q.push(S);
11     while (!q.empty()) { int u = q.front(); q.pop(); for (int k = 0; k < int(g[u].size()); k++) { Edge

13 }

15     if (u == T) return f;
16     for (int &k = it[u]; k < int(g[u].size()); k++) {
17         int id = g[u][k]; Edge &x = e[id];
18         if (x.cap > 0 && level[x.to] == level[u] + 1) { int got = dfs(x.to, min(f, x.cap)); if (got) { 
x.cap -= got; e[id ^ 1].cap += got; return got; } }
19     }
20     return 0;

33.3 endpos	 与后缀树
Equivalence	classes;	three	views	of	one	object.
IDEA endpos	and	equivalence	classes: endpos(t) = the set of positions where substring t ends in s. Substrings
with the same endpos form one class, and each class is one state of the suffix automaton ( 第 3 章 ). Within a
class the strings are suffixes of each other with consecutive lengths len[link[v]] + 1 … len[v]; a shorter
suffix has a larger (or equal) endpos set, which is why suffix links point to the next larger set and form a
tree.
KEY POINT The number of occurrences of a state = |endpos| = the number of prefix-end states in its link subtree; that
is the counting used in 第 3 章 's sam.cpp.
IDEA A suffix	tree ( 后缀树 ) is the trie of all suffixes of s$ with every chain of single-child nodes compressed
into one edge labelled by a substring: at most 2n nodes. Each leaf is a suffix; the path label of an internal
node is a substring that repeats.
KEY POINT Three structures, one object: the suffix tree of s is the link tree of the suffix automaton of reversed s; its
leaves read in lexicographic edge order give the suffix	array, and the string depth of the LCA of two leaves
is their LCP (height). In contests the suffix array or SAM replaces an explicit suffix tree (Ukkonen's
construction is long and error-prone).

Key	points	to	memorise
1. ISAP: labels from one BFS from t; push on d[u] = d[v] + 1; relabel to min + 1.

3. Mixed Euler: orient arbitrarily, x = out − in must be even; flow fixes x/2.
4. endpos classes = SAM states; lengths len[link]+1 … len.
5. Suffix tree of s = SAM link tree of reversed s; leaves in order = SA; LCA depth = LCP.
