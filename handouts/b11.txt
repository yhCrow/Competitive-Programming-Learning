IDEA Recurrence ( 递推 ) builds the answer
for size i from answers already found
for smaller sizes, filling a table from the
bottom up. Four things define it, and
you should write all four down before
coding:
1. State: what f[i] means, in one sentence.
2. Transition: how f[i] is made from earlier entries.
3. Base	cases: the first entries, set by hand.
4. Order: fill so every entry needed is already known.

Build answers bottom-up from smaller ones (recurrence), or top-down by solving the same problem on
smaller input (recursion).

1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 // big numbers, ones digit first ( 第 8 章 )
5 vector<int> add(const vector<int> &a, const vector<int> &b) {
6     vector<int> c;
7     int carry = 0;
8     for (size_t i = 0; i < max(a.size(), b.size()) || carry; i++) {
9         int s = carry;
10         if (i < a.size()) s += a[i];
11         if (i < b.size()) s += b[i];
12         c.push_back(s % 10);
13         carry = s / 10;
14     }
15     return c;
16 }
17  
18 int main() {
19     int n;
20     cin >> n;
21     vector<int> f1 = {1}, f2 = {2};      // f[1] = 1, f[2] = 2
22     if (n == 1) f2 = f1;
23     for (int i = 3; i <= n; i++) {
24         vector<int> f3 = add(f1, f2);    // f[i] = f[i-1] + f[i-2]
25         f1 = f2;
26         f2 = f3;
27     }
28     for (int i = int(f2.size()) - 1; i >= 0; i--) cout << f2[i];
29     cout << "\n";
30     return 0;
31 }

Step For the stairs
state f[i] = number of ways to reach step i
transition the last move was 1 step (from i − 1) or 2 steps (from i − 2): f[i] = f[i−1] + f[i−2]
base f[1] = 1, f[2] = 2
order i increasing
KEY POINT The values grow like Fibonacci numbers: f[5000] has over 1000 digits, so the table holds big numbers
from 第 8 章  (P1255). Only the last two entries are needed, so two variables replace the whole table. A bee
walking from cell m to cell n is the same recurrence with n − m steps (P2437).

11.1.2 Paths	in	a	grid
1 1 1 1 1
1 x 1 2 3
1 1 x 2 5
1 2 2 4 9
IDEA A pawn moves only right or down. The number of ways to reach a cell
= ways to the cell above + ways to the cell on the left; blocked cells (x)
have 0 ways. Fill row by row, so both neighbours are ready.
KEY POINT Here 9 = 5 (above) + 4 (left). The first row and first column have
exactly 1 way each until a blocked cell cuts them off.
pawn_paths.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 long long f[25][25];
5 bool blocked[25][25];
6  
7 int main() {
8     int n, m, hx, hy;
9     cin >> n >> m >> hx >> hy;           // target (n, m), horse at (hx, hy)
10     int dx[9] = {0, 1, 1, -1, -1, 2, 2, -2, -2};   // the horse and
11     int dy[9] = {0, 2, -2, 2, -2, 1, -1, 1, -1};   // its 8 attacks
12     for (int k = 0; k < 9; k++) {
13         int x = hx + dx[k], y = hy + dy[k];
14         if (x >= 0 && x <= n && y >= 0 && y <= m) blocked[x + 1][y + 1] = true;
15     }
16     f[1][0] = 1;                         // shift by 1: f[1][1] gets 1 way
17     for (int i = 1; i <= n + 1; i++)
18         for (int j = 1; j <= m + 1; j++)
19             f[i][j] = blocked[i][j] ? 0 : f[i - 1][j] + f[i][j - 1];
20     cout << f[n + 1][m + 1] << "\n";
21     return 0;
22 }
INPUT
6 6 3 3
OUTPUT
6
KEY POINT Shifting every coordinate by 1 gives the table a row 0 and column 0 of zeros, so the edges need no special
case. The counts reach about 1017 for a 20 × 20 board: use long long  (P1002).

1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 int f[10005];                         // f[j]: ways to spend exactly j
5  
6 int main() {
7     int n, m;
8     cin >> n >> m;
9     f[0] = 1;                         // spend nothing: one way
10     for (int i = 0; i < n; i++) {
11         int a;
12         cin >> a;
13         for (int j = m; j >= a; j--)  // downwards: each dish once
14             f[j] += f[j - a];
15     }
16     cout << f[m] << "\n";
17     return 0;
18 }
INPUT
4 4
1 1 2 2
OUTPUT
3
IDEA Count the ways to spend exactly m on distinct dishes. Add dishes one at a time; with dish a, every amount
j gains the ways that reached j − a before (P1164).
TRAP Loop j downwards. Going upwards would let the same dish be used again within one round.
KEY POINT Tiling a 2 × n wall with dominoes and L-shapes: list how the right end can look, and write one transition
per shape (P1990).
11.2 递归思想
Solve	the	same	problem	on	smaller	input:	Hanoi,	memoisation,	nested	text,	divide	and	conquer.
IDEA Recursion ( 递归 ) writes the answer for a problem in terms of the same problem on smaller input, top-
down. It suits problems whose structure is nested: expressions inside brackets, a board split into
quarters, a string built from copies of itself.

11.2.1 Tower	of	Hanoi
hanoi.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 int moves = 0;
5  
6 // move n disks from peg a to peg c, using b
7 void hanoi(int n, char a, char b, char c) {
8     if (n == 0) return;
9     hanoi(n - 1, a, c, b);            // top n-1 out of the way
10     cout << a << "->" << c << "\n";   // largest disk
11     moves++;
12     hanoi(n - 1, b, a, c);            // n-1 back on top
13 }
14  
15 int main() {
16     int n;
17     cin >> n;
18     hanoi(n, 'A', 'B', 'C');
19     cout << moves << " moves\n";
20     return 0;
21 }
INPUT
3
OUTPUT
A->C
A->B
C->B
A->C
B->A
B->C
A->C
7 moves
IDEA To move n disks, trust the function to move n − 1: clear them to the spare peg, move the largest, then bring
the n − 1 back. The base case n = 0 does nothing. The count is 2n − 1.
KEY POINT Write the recursive call as if it already works for smaller n; then only one level has to be right. Moving
black and white pieces into alternate order (P1259) has the same "solve n from n − 1" structure.

11.2.2 Memoised	recursion
w_function.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 long long memo[21][21][21];
5 bool done[21][21][21];
6  
7 long long w(long long a, long long b, long long c) {
8     if (a <= 0 || b <= 0 || c <= 0) return 1;
9     if (a > 20 || b > 20 || c > 20) return w(20, 20, 20);
10     if (done[a][b][c]) return memo[a][b][c];       // already known
11     long long r;
12     if (a < b && b < c) r = w(a, b, c - 1) + w(a, b - 1, c - 1) - w(a, b - 1, c);
13     else r = w(a - 1, b, c) + w(a - 1, b - 1, c) + w(a - 1, b, c - 1) - w(a - 1, b - 1, c - 1);
14     done[a][b][c] = true;
15     return memo[a][b][c] = r;
16 }
17  
18 int main() {
19     long long a, b, c;
20     while (cin >> a >> b >> c && !(a == -1 && b == -1 && c == -1))
21         cout << "w(" << a << ", " << b << ", " << c << ") = " << w(a, b, c) << "\n";
22     return 0;
23 }

-1 -1 -1

w(2, 2, 2) = 4
w(15, 15, 15) = 32768
KEY POINT The plain recursion calls itself several times per level and explodes. Only 20 × 20 × 20 different
arguments can occur, so store each result the first time (P1464). Check the guard order exactly as the
statement gives it: the "≤ 0" rule comes before the "> 20" rule.

7 // decode from s[pos] until ']' or the end
8 string decode() {
9     string out;
10     while (pos < s.size() && s[pos] != ']') {
11         if (s[pos] == '[') {
12             pos++;                            // skip '['
13             int k = 0;
14             while ('0' <= s[pos] && s[pos] <= '9') k = k * 10 + (s[pos++] - '0');
15             string inner = decode();          // the bracket's content
16             pos++;                            // skip ']'
17             for (int i = 0; i < k; i++) out += inner;
18         } else {
19             out += s[pos++];
20         }
21     }
22     return out;
23 }

11.2.4 Divide	and	conquer:	halves	and	quarters
cow_code.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 int main() {
5     string s;
6     long long n;
7     cin >> s >> n;                        // 1-based position
8     long long len = s.size();
9     while (len < n) len *= 2;             // smallest doubled length
10     while (n > int(s.size())) {
11         long long half = len / 2;
12         if (n > half) {                   // in the rotated copy
13             n -= half;
14             n = (n == 1) ? half : n - 1;  // undo the rotation
15         }
16         len = half;
17     }
18     cout << s[n - 1] << "\n";
19     return 0;
20 }

IDEA Each doubling appends a copy rotated by one place. A position in the second half maps back to one
position in the first half, so halve until the position lies inside the original string: O(log n) steps even for n
= 1018 (P3612).
KEY POINT Board and picture problems split the same way: a 2k board with one missing cell is covered by placing
one L-shape in the centre and solving four quarters (P1228); the totem picture is three copies of the
smaller picture (P1498).
11.3 课后习题与实验
The	Luogu	problems	for	this	chapter,	a	ladder	through	them,	and	experiments	to	try	yourself.
Key	points	to	memorise
1. Recurrence: write the state, transition, base	cases and order before coding.
2. Stairs: f[i] = f[i−1] + f[i−2]; counts grow fast → long long or big numbers.
3. Grid paths: f[i][j] = f[i−1][j] + f[i][j−1]; blocked cells are 0; pad row 0 and column 0.
4. Catalan: f[i] = Σ f[k] · f[i−1−k] (stack orders, brackets, trees).
5. Exact-sum counting with each item once: loop the amount downwards.
6. Recursion: trust the call for smaller input; get one level and the base case right.
7. Hanoi: n−1 aside, move the largest, n−1 back; 2ⁿ − 1 moves.
8. Repeated arguments → memoise; keep the statement's guard order.
9. Nested text → a recursive parser that returns at the closing bracket.
10. Huge positions in self-similar strings → map back through halvings in O(log n).
