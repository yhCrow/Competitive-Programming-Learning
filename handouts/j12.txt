IDEA A bridge ( 桥 , 割边 ) is an edge whose
removal disconnects the graph: here 3–4
and 5–7 (dashed). Tarjan's idea: DFS
gives each node a time dfn[u]; low[u] is
the smallest dfn reachable from u's
subtree using at most one non-tree edge.
KEY POINT Tree edge u → v is a bridge exactly when
low[v]	>	dfn[u]: nothing in v's subtree
can climb back to u or above without
that edge. One DFS, O(n + m).
Edge (u, v) seen from u Update
tree edge: v not visited yet dfs(v), then low[u] = min(low[u], low[v])
back edge: v already visited (not the edge we came in on) low[u] = min(low[u], dfn[v])
深 入 浅 出 程 序 设 计 竞 赛  · 进 阶 篇  · 第 3 部 分  图 论
One idea, dfn and low, finds bridges, cut vertices, biconnected components and strongly connected
components; shrinking components turns graphs into trees and DAGs, and 2-SAT falls out for free.

7 vector<pair<int, int>> bridges;

9 void tarjan(int u, int inEdge) {
10     dfn[u] = low[u] = ++timer;
11     for (int k = 0; k < int(g[u].size()); k++) {
12         int v = g[u][k].first, id = g[u][k].second;
13         if (id == inEdge) continue;              // not back along the same edge
14         if (!dfn[v]) {
15             tarjan(v, id);
16             low[u] = min(low[u], low[v]);
17             if (low[v] > dfn[u]) bridges.push_back(make_pair(min(u, v), max(u, v)));
18         } else low[u] = min(low[u], dfn[v]);     // back edge
19     }
20 }

IDEA Remove all bridges: what stays connected are the edge-biconnected	components ( 边双连通分量 ):
inside one, any two nodes have two edge-disjoint paths. Shrinking each component to a point turns the
graph into a tree whose edges are the bridges.
KEY POINT To make the whole graph bridge-free, join leaves of that tree in pairs: ⌈leaves / 2⌉ new edges (P2860). Here
the tree is {1,2,3} – {4,5,6} – {7}: two leaves, one new road. "Most bosses on one path" (CF1000E) is the
diameter of the same tree.

IDEA A cut	vertex ( 割点 ) is a node whose
removal disconnects the graph: here 3, 4
and 5. Same dfn / low. A non-root u is a
cut vertex if some child v has low[v]	≥
dfn[u] (v's subtree cannot get above u).
The root is a cut vertex if it has two	or
more DFS children.
KEY POINT Compare with bridges: ≥ for nodes, > for
edges. For cut vertices a back edge to u
itself still leaves v's subtree stuck
below u, so equality counts.

IDEA Vertex-biconnected	components ( 点双连通分量 , blocks): maximal parts with no cut vertex of their
own. A cut vertex belongs to several blocks (3 is in {1,2,3} and {3,4}). Keep a stack of nodes; when low[v]
≥ dfn[u], pop down to v, and the popped nodes plus u form a block.
KEY POINT Joining each block (a "square" node) to its members gives the block-cut	tree ( 圆方树 ): any graph
question about "nodes every path must pass" becomes a tree path question (P4630 铁人两项 , P4606,
CF487E).
12.3 有向图的强连通性
Tarjan	SCC,	condensation	DP,	2-SAT.
1 2
3 4
5
one SCC: weight 1+2+3
weights = node ids
IDEA In a directed graph, a strongly
connected	component ( 强连通分量 ,
SCC) is a maximal set where every node
reaches every other. Tarjan again: keep a
stack of visited nodes still waiting for a
component; low[u] uses only edges to
nodes still	on	the	stack. When low[u]
== dfn[u], u is the first node of its SCC:
pop down to u.
KEY POINT Shrinking every SCC to one node ( 缩点 )
leaves a DAG. Tarjan numbers the SCCs
in reverse	topological	order (a
component is finished after everything
it reaches), so a DP over the DAG can
simply run from the largest SCC number
down.

scc_dp.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 const int N = 10005;
5 vector<int> g[N], dag[N];
6 int n, m, w[N], dfn[N], low[N], timer = 0, scc[N], cnt = 0;
7 long long sw[N], best[N];
8 bool onStack[N];
9 vector<int> stk;
10  
11 void tarjan(int u) {
12     dfn[u] = low[u] = ++timer;
13     stk.push_back(u); onStack[u] = true;
14     for (int k = 0; k < int(g[u].size()); k++) {
15         int v = g[u][k];
16         if (!dfn[v]) { tarjan(v); low[u] = min(low[u], low[v]); }
17         else if (onStack[v]) low[u] = min(low[u], dfn[v]);   // finished SCCs are ignored
18     }
19     if (low[u] == dfn[u]) {                     // u is the root of an SCC
20         cnt++;
21         while (true) {
22             int x = stk.back();
23             stk.pop_back(); onStack[x] = false;
24             scc[x] = cnt; sw[cnt] += w[x];
25             if (x == u) break;
26         }
27     }
28 }
29  
30 int main() {
31     cin >> n >> m;
32     for (int i = 1; i <= n; i++) cin >> w[i];
33     vector<int> ea(m), eb(m);
34     for (int i = 0; i < m; i++) { cin >> ea[i] >> eb[i]; g[ea[i]].push_back(eb[i]); }
35     for (int i = 1; i <= n; i++) if (!dfn[i]) tarjan(i);
36     for (int i = 0; i < m; i++)
37         if (scc[ea[i]] != scc[eb[i]]) dag[scc[ea[i]]].push_back(scc[eb[i]]);
38     long long ans = 0;
39     for (int c = cnt; c >= 1; c--) {            // topological order: high numbers first
40         best[c] = max(best[c], 0LL) + sw[c];    // best path ending in c
41         ans = max(ans, best[c]);
42         for (int k = 0; k < int(dag[c].size()); k++) {
43             int t = dag[c][k];
44             best[t] = max(best[t], best[c]);
45         }
46     }
47     cout << ans << "\n";
48     return 0;
49 }

11进阶篇  第 12 章  连通性问题
IDEA 2-SAT: n boolean variables, each clause "xi = a or xj = b". Make two nodes per variable (true / false); a
clause gives two implications "if not this, then that". It is unsatisfiable exactly when some x and ¬x are in
the same	SCC (P4782).
KEY POINT Choosing values: take for each variable the side whose SCC comes later in topological order, i.e. the
smaller Tarjan number. Then no chosen node implies its own opposite. Problems with "choose one of
two per item" plus pairwise conflicts are 2-SAT (P3825 游戏 ).
12.4 课后习题与实验
The	Luogu	problems	for	this	chapter,	a	ladder	through	them,	and	experiments	to	try	yourself.
Key	points	to	memorise
1. dfn[u]: DFS time; low[u]: smallest dfn reachable from u's subtree with one back edge.
2. Bridge u → v: low[v] > dfn[u]. Skip the incoming edge	id (parallel edges).
3. Cut vertex: non-root with a child low[v] ≥ dfn[u]; root with ≥ 2 DFS children.
4. Edge-BCCs: remove bridges; the components form a tree. Make bridge-free: ⌈leaves / 2⌉.
5. Vertex-BCCs: node stack; on low[v] ≥ dfn[u] pop to v, add u. Block-cut tree.
6. SCC: stack + onStack; low uses only nodes on the stack; root when low == dfn.
7. Tarjan SCC numbers = reverse topological order. Condense ⇒ DAG ⇒ DP.
8. 2-SAT: (a ∨ b) ⇒ ¬a → b, ¬b → a; impossible iff x, ¬x share an SCC; pick the smaller Tarjan number.
