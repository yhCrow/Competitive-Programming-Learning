IDEA A spanning	tree ( 生成树 ) uses n − 1
edges to connect all n nodes; a
minimum	spanning	tree (MST) has
the smallest total weight. Kruskal: sort
the edges by weight; take an edge if its
ends are in different components
(union-find, 基础篇  第 17 章 ), otherwise
skip it. Stop after n − 1 edges.
KEY POINT Cut	property: for any split of the nodes
into two groups, the lightest edge
crossing it belongs to some MST.
Kruskal's next edge is always the
lightest edge leaving its component, so
every taken edge is safe. O(m log m) for
the sort.

Connect every node as cheaply as possible with Kruskal or Prim, turn per-node costs into a virtual node,
answer bottleneck queries on the spanning tree, and find the strict second-best tree.

IDEA Check connectivity: if fewer than n − 1 edges were taken, there is no spanning tree (P3366 prints orz).
Stopping at n − 1 edges saves time but is not needed for correctness.
KEY POINT Kruskal also builds a minimum spanning forest: stop early when exactly k components remain, and the
remaining components are the best k clusters (P1195 口袋的天空 ). The k − 1 heaviest MST edges cut are
the "largest gaps" between clusters.

10     cin >> n >> m;
11     for (int i = 1; i <= n; i++) for (int j = 1; j <= n; j++) w[i][j] = INF;
12     for (int i = 0; i < m; i++) {

16         w[u][v] = w[v][u] = min(w[u][v], c);
17     }
18     for (int i = 1; i <= n; i++) d[i] = INF;
19     d[1] = 0;
20     long long total = 0;
21     for (int step = 0; step < n; step++) {
22         int u = 0;
23         for (int i = 1; i <= n; i++)          // closest node not yet in the tree
24             if (!in[i] && (u == 0 || d[i] < d[u])) u = i;
25         if (d[u] == INF) { cout << "orz\n"; return 0; }
26         in[u] = true;
27         total += d[u];
28         for (int v = 1; v <= n; v++)          // d[v] = cheapest edge from the tree to v
29             if (!in[v] && w[u][v] < d[v]) d[v] = w[u][v];
30     }
31     cout << total << "\n";
32     return 0;
33 }

IDEA Prim grows one tree from node 1, always adding the node with the cheapest edge into the tree, exactly like
Dijkstra but with d[v] = one	edge weight instead of a path length.
KEY POINT The plain O(n²) version is best for dense graphs given as a matrix (m ≈ n²), where sorting all edges for
Kruskal would cost more. With a heap it is O(m log n), but on sparse graphs Kruskal is simpler.

IDEA Virtual	node ( 超级源点 ): a cost paid at a node by itself (dig a well, build a power station) becomes an

1 #include <bits/stdc++.h>

5 struct Edge { int u, v, w; };
6 bool heavier(const Edge &a, const Edge &b) { return a.w > b.w; }
7 int fa[N], dep[N], up[N][LOG], low[N][LOG], comp[N];
8 vector<pair<int, int>> g[N];
9 int find(int x) { return fa[x] == x ? x : fa[x] = find(fa[x]); }
10  
11 void dfs(int u, int p, int w, int c) {
12     comp[u] = c;
13     up[u][0] = p; low[u][0] = w;               // low = smallest edge on the jump
14     for (int k = 1; k < LOG; k++) {
15         up[u][k] = up[up[u][k - 1]][k - 1];
16         low[u][k] = min(low[u][k - 1], low[up[u][k - 1]][k - 1]);
17     }
18     for (int i = 0; i < int(g[u].size()); i++) {
19         int v = g[u][i].first;
20         if (v != p) { dep[v] = dep[u] + 1; dfs(v, u, g[u][i].second, c); }
21     }
22 }
23  
24 int query(int u, int v) {                      // smallest edge on the tree path u..v
25     int r = INT_MAX;
26     if (dep[u] < dep[v]) swap(u, v);
27     for (int k = LOG - 1; k >= 0; k--)
28         if (dep[u] - (1 << k) >= dep[v]) { r = min(r, low[u][k]); u = up[u][k]; }
29     if (u == v) return r;
30     for (int k = LOG - 1; k >= 0; k--)
31         if (up[u][k] != up[v][k]) { r = min(r, min(low[u][k], low[v][k])); u = up[u][k]; v = up[v][k]; }
32     return min(r, min(low[u][0], low[v][0]));
33 }

KEY POINT Bottleneck	paths: the route between x and y whose smallest edge is as large as possible always runs
along the maximum spanning tree (P1967 货车运输 ). So build that tree once, then answer each query as
the minimum edge on a tree path, with binary lifting as in 第 9 章  (low[u][k] next to up[u][k]). The
minimum spanning tree likewise minimises the largest edge (P1396 营救 ).
TRAP The graph may be disconnected: run the DFS from every unvisited node, keep a component id, and answer
−1 across components. Node 0 is the sentinel above every root, so its low[] must be +∞.
11.2 次小生成树 ( 选读 )
Swap	one	edge;	largest	and	strict	second	largest	on	a	path.
IDEA The second-best	spanning	tree ( 次小生成树 ): every other spanning tree is reached from the MST by
adding one non-tree edge (u, v, w) and removing an edge on the tree path u–v. To keep the total as small as
possible, remove the largest path edge: new total = MST − max + w.
KEY POINT For the strict second-best (P4180), the result must be larger than the MST. If w equals the path maximum,
remove the largest path edge that is strictly	smaller than w instead. So each binary-lifting jump stores the
largest and the strictly second-largest edge.

5 struct Edge { int u, v; long long w; bool inTree; };
6 bool byWeight(const Edge &a, const Edge &b) { return a.w < b.w; }
7 int fa[N], dep[N], up[N][LOG];
8 long long m1[N][LOG], m2[N][LOG];               // largest, strictly second largest
9 vector<pair<int, long long>> g[N];

11  
12 void add(long long &a, long long &b, long long x) {   // put x into the pair (a > b)
13     if (x > a) { b = a; a = x; }
14     else if (x < a && x > b) b = x;
15 }
16  
17 void dfs(int u, int p) {
18     for (int k = 1; k < LOG; k++) {
19         int mid = up[u][k - 1];
20         up[u][k] = up[mid][k - 1];
21         m1[u][k] = m1[u][k - 1]; m2[u][k] = m2[u][k - 1];
22         add(m1[u][k], m2[u][k], m1[mid][k - 1]);
23         add(m1[u][k], m2[u][k], m2[mid][k - 1]);
24     }
25     for (int i = 0; i < int(g[u].size()); i++) {
26         int v = g[u][i].first;
27         if (v == p) continue;
28         dep[v] = dep[u] + 1; up[v][0] = u; m1[v][0] = g[u][i].second; m2[v][0] = -1;
29         dfs(v, u);
30     }
31 }

33 void pathMax(int u, int v, long long &a, long long &b) {   // top two on path u..v
34     a = b = -1;
35     if (dep[u] < dep[v]) swap(u, v);
36     for (int k = LOG - 1; k >= 0; k--)
37         if (dep[u] - (1 << k) >= dep[v]) { add(a, b, m1[u][k]); add(a, b, m2[u][k]); u = up[u][k]; }
38     if (u == v) return;
39     for (int k = LOG - 1; k >= 0; k--)
40         if (up[u][k] != up[v][k]) {
41             add(a, b, m1[u][k]); add(a, b, m2[u][k]); add(a, b, m1[v][k]); add(a, b, m2[v][k]);
42             u = up[u][k]; v = up[v][k];
43         }
44     add(a, b, m1[u][0]); add(a, b, m1[v][0]);
45 }

KEY POINT MST = 1 + 2 + 3 + 4 = 10. Edge 3–4 (w = 3) closes the cycle 3–1–2–4 whose edges are 2, 1, 3: the largest
equals w, so swap out the strict second, 2: 10 − 2 + 3 = 11. Edge 4–5 (w = 6) gives 10 − 4 + 6 = 12. Answer

TRAP Merging two (largest, second) pairs must keep the second strictly smaller: the add  helper ignores a value
equal to the current largest. Weights are non-negative here, so −1 can mean "none".
11.3 课后习题与实验
The	Luogu	problems	for	this	chapter,	a	ladder	through	them,	and	experiments	to	try	yourself.
Key	points	to	memorise
1. MST: n − 1 edges, minimum total; cut property: lightest crossing edge is safe.
2. Kruskal: sort edges, take if find(u) ≠ find(v); O(m log m).
3. Fewer than n − 1 edges taken ⇒ not connected.
4. Prim: grow from one node, d[v] = cheapest single edge into the tree; O(n²) for dense graphs.
5. Per-node cost ⇒ edge to a virtual node 0.
6. Best bottleneck path lies on the maximum (or minimum) spanning tree.
7. Second MST: add a non-tree edge w, remove the largest path edge: MST − max + w.
8. Strict: if w == max, remove the strict second largest instead.
