23.1 拉格朗日插值
Polynomial	through	n	points;	evaluate	at	k.
IDEA Lagrange	interpolation ( 拉格朗日插值 ): the unique polynomial of degree < n through n points (xi, yi) is
f(x) = Σi yi · Πj≠i (x − xj)/(xi − xj). Each term is 1 at xi and 0 at every other xj. Evaluating at one k costs
O(n²), or O(n) when the xi are 0, 1, …, n − 1 (prefix and suffix products).
KEY POINT Use it when an answer is known to be a polynomial in k of small degree (sums of powers 1d + … + kd
have degree d + 1): compute it for d + 2 small k by brute force, then interpolate to a huge k.
竞 赛 拓 展 专 题  · 拓 展 篇  · 数 学 拓 展
Recover a polynomial from points, count labelled trees with Prüfer sequences, count colourings up to
symmetry with Burnside and Pólya, and count spanning trees with a determinant.

23.2 Prüfer	 序列
Smallest-leaf	encoding;	Cayley	n^(n−2).
IDEA A Prüfer	sequence (Prüfer 序列 ) encodes a labelled tree on n vertices as a list of n − 2 labels: repeatedly
remove the smallest	leaf and write down its neighbour. Decoding reverses it. The map is a bijection, so
there are exactly nn−2 labelled trees (Cayley's	formula).
KEY POINT A vertex appears in the sequence exactly (degree − 1) times. So the number of trees with given degrees d1,
…, dn is (n − 2)! / Π (di − 1)! ( 树的计数  P2290). Both directions run in O(n) with a moving pointer to the
smallest leaf (P6086).

1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 int main() {
5     int n;
6     cin >> n;
7     vector<int> fa(n + 1, 0), deg(n + 1, 0);
8     for (int i = 1; i < n; i++) { int a, b; cin >> a >> b; fa[a] = b; }    // edges given child -> 
parent (root n)
9     for (int i = 1; i < n; i++) deg[fa[i]]++;                              // number of children
10     vector<int> code;
11     int ptr = 1;
12     while (deg[ptr] != 0) ptr++;                    // smallest leaf
13     int leaf = ptr;
14     for (int i = 0; i < n - 2; i++) {
15         int f = fa[leaf];
16         code.push_back(f);
17         if (--deg[f] == 0 && f < ptr) leaf = f;     // the parent became a smaller leaf: use it now
18         else { ptr++; while (deg[ptr] != 0) ptr++; leaf = ptr; }   // next smallest leaf
19     }
20     for (int i = 0; i < n - 2; i++) cout << code[i] << " ";
21     cout << "\n";
22     return 0;
23 }

IDEA Tree: 1, 2, 3 hang on 4; then 4 – 5 – 6 – 7, rooted at 7. Removing smallest leaves writes 4, 4, 4, 5, 6
(checked in Python). The trick: when a removed leaf's parent becomes a leaf with a smaller label than the
pointer, it is the next smallest leaf, so use it immediately.
KEY POINT With the root fixed at n (never removed), edges can be stored as parent pointers, which makes O(n)
encoding a single pass.
23.3 Burnside	 与 	Pólya
Average	fixed	colourings;	necklaces.
IDEA Burnside's	lemma (Burnside 引理 ): the number of colourings that are different up to a group of
symmetries = the average number of colourings fixed by each symmetry. For rotations of an n-bead
necklace with m colours, rotation by k fixes mgcd(k, n) colourings: answer = (1/n) Σk mgcd(k, n).
KEY POINT Pólya (Pólya 定理 ) is the same count written with cycles: each symmetry fixes m(number of cycles)
colourings. Grouping rotations by d = gcd(k, n) gives (1/n) Σd | n φ(n/d) md, fast even for n = 10⁹ (P4980).

10 long long phi(long long n) {
11     long long r = n;
12     for (long long p = 2; p * p <= n; p++)
13         if (n % p == 0) { r = r / p * (p - 1); while (n % p == 0) n /= p; }
14     if (n > 1) r = r / n * (n - 1);
15     return r;
16 }

23.4 矩阵树定理
Laplacian	minor	determinant.
IDEA The matrix-tree	theorem ( 矩阵树定理 , Kirchhoff): build the Laplacian L = D − A (degrees on the
diagonal, −1 per edge off the diagonal, multi-edges counted). The number of spanning trees equals the
determinant of L with any one row and the same column removed. Weighted edges give the sum over
spanning trees of the product of weights.

KEY POINT The determinant is Gaussian elimination ( 进阶篇  第 22 章 ), mod a prime with inverses or mod anything
with row-Euclid. Directed versions count arborescences (out-trees / in-trees) using in- or out-degrees
(P6178).
matrix_tree.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 const long long MOD = 1000000007;
5 long long power(long long a, long long b) {
6     long long r = 1;
7     for (a %= MOD; b > 0; b >>= 1, a = a * a % MOD) if (b & 1) r = r * a % MOD;
8     return r;
9 }
10  
11 int main() {
12     int n, m;
13     cin >> n >> m;
14     vector<vector<long long>> L(n, vector<long long>(n, 0));
15     for (int i = 0; i < m; i++) {
16         int u, v; cin >> u >> v; u--; v--;
17         L[u][u]++; L[v][v]++;                         // degrees
18         L[u][v] = (L[u][v] - 1 + MOD) % MOD;          // -1 per edge
19         L[v][u] = (L[v][u] - 1 + MOD) % MOD;
20     }
21     int k = n - 1;                                    // drop the last row and column
22     long long det = 1;
23     for (int c = 0; c < k; c++) {
24         int piv = -1;
25         for (int r = c; r < k; r++) if (L[r][c]) { piv = r; break; }
26         if (piv < 0) { cout << 0 << "\n"; return 0; } // disconnected graph
27         if (piv != c) { swap(L[piv], L[c]); det = (MOD - det) % MOD; }
28         det = det * L[c][c] % MOD;
29         long long inv = power(L[c][c], MOD - 2);
30         for (int r = c + 1; r < k; r++) {
31             long long f = L[r][c] * inv % MOD;
32             for (int j = c; j < k; j++) L[r][j] = ((L[r][j] - f * L[c][j]) % MOD + MOD) % MOD;
33         }
34     }
35     cout << det << "\n";
36     return 0;
37 }

23.5 课后习题与实验
The	Luogu	problems	for	this	chapter,	a	ladder	through	them,	and	experiments	to	try	yourself.
Key	points	to	memorise
1. Lagrange: f(k) = Σ yᵢ Π (k − xⱼ)/(xᵢ − xⱼ); O(n²), one inverse per term.
2. Polynomial of degree d: compute d + 1 values, interpolate to any k.
3. Prüfer: remove smallest leaf, write its neighbour; vertex appears deg − 1 times.
4. Cayley: n^(n−2) labelled trees; given degrees: (n−2)!/Π(dᵢ − 1)!.
5. Burnside: average of fixed colourings; rotation by k fixes m^gcd(k, n).
6. Pólya: (1/n) Σ_{d|n} φ(n/d) m^d for necklaces.
7. Matrix-tree: det of the Laplacian minus one row and column.
