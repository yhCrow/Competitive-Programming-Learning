6.1 字符数组
Text	as	an	array	of	chars	ending	in	\0,	and	walking	through	characters.
IDEA A character	array char a[105]  stores text one character per box, followed by an invisible end marker
'\0' . C++ can read and print it with cin  and cout ; you walk it until you meet the end marker. In C++
programs a string  (6.2) is usually easier, but char arrays appear in many older solutions and in grids.

6.3.1 Redirection	on	the	command	line
Command Effect
a < in.txt cin reads from in.txt instead of the keyboard
a > out.txt cout writes to out.txt instead of the screen
a < in.txt > out.txt both
fc out.txt ans.txt  (Windows) / diff out.txt ans.txt compare your output with the expected answer
KEY POINT Redirection needs no code changes, so it is the quickest way to rerun a long sample. Keep the sample input
in a file and compare outputs with fc  / diff  instead of by eye.
C C LANGUAGE · ADDITIONAL INFORMATION
The C way, still required by some contests (for example NOIP-style rules that name the input and output files): freopen
from <cstdio>  reconnects stdin /stdout , and therefore cin /cout , to files. Put it at the start of main ; the rest of the
program is unchanged.
TRAP Comment out freopen  when testing by hand, or the program waits on a file instead of the keyboard.
Luogu itself reads standard input: submit without freopen  unless the problem asks for files.
