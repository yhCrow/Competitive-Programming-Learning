1.2 简单数学运算
Operators,	their	order,	and	integer	versus	real	division.
IDEA C++ evaluates arithmetic like a calculator, with the usual order: brackets first, then * / % , then + - , left
to right within a level. With two integers, /  drops the fraction and %  gives the remainder.

1.3 变量与常量
Named	boxes	for	values,	and	values	that	never	change.
3→5
a
5→3
b
3
t
t = a; a = b; b = t;
IDEA A variable is a named box that holds one value of a
fixed type. int a;  creates it, a = 5;  puts a value in
(the old value is gone), and cin >> a;  fills it from
the input.
KEY POINT To swap two boxes you need a third: copying a = b
first would destroy a. (swap(a, b)  does the same
for you.)

1.4 课后习题与实验
The	Luogu	problems	for	this	chapter,	a	ladder	through	them,	and	experiments	to	try	yourself.
Key	points	to	memorise
1. A program turns input into output by exact steps; test on samples and your own cases.
2. Every statement ends with ;; blocks use {	}; main runs first.
3. Raw strings R"(...)" print backslashes and quotes as typed.
4. Order: brackets, then * / %, then + −; int / int drops the fraction toward 0.
5. -7	%	3	==	-1; ceil(a / b) = (a	+	b	-	1)	/	b.
6. A variable is a typed box; = assigns, == compares.
7. Swap needs a third box (or swap); constants are const.
8. Your template: #define	int	long	long → printf needs %lld; double is long double; endl does not flush.
