8.1 线性规划与单纯形
Tableau,	entering	and	leaving	variables,	pivots.
IDEA A linear	program ( 线性规划 ): maximise c·x subject to Ax ≤ b and x ≥ 0. The optimum, if finite, is attained
at a vertex of the feasible polytope. The simplex	method ( 单纯形法 ) walks from vertex to better
neighbouring vertex: pick a variable with positive objective coefficient (entering), find the constraint that
limits it first (minimum ratio test: leaving), and pivot. When no coefficient is positive, the current vertex
is optimal.
KEY POINT If the entering column has no positive entry, the objective can grow forever: unbounded. If some bi < 0
the origin is not feasible, and an initialisation phase (an auxiliary LP) is needed first. Bland's rule
(smallest index) avoids cycling. Exponential in theory, fast in practice.
竞 赛 拓 展 专 题  · NOI 篇  · NOI 专 题
Maximise a linear objective under linear constraints by pivoting from vertex to better vertex, detect
unboundedness, and know when duality helps.

4 const double EPS = 1e-9;
5 int n, m;
6 vector<vector<double>> a;                     // a[0][1..n]: objective; a[i][0]: b_i; a[i][1..n]: row i
7  
8 void pivot(int l, int e) {                    // row l leaves, column e enters
9     double t = a[l][e];
10     a[l][e] = 1;
11     for (int j = 0; j <= n; j++) a[l][j] /= t;
12     for (int i = 0; i <= m; i++) {
13         if (i == l || fabs(a[i][e]) < EPS) continue;
14         double f = a[i][e];
15         a[i][e] = 0;
16         for (int j = 0; j <= n; j++) a[i][j] -= f * a[l][j];
17     }
18 }

KEY POINT Each column stands for a variable that is currently non-basic (0); pivoting swaps a basic and a non-basic
variable. The first two LPs are checked against trying every vertex (every choice of n tight constraints)
with exact fractions in Python; the third, x − y ≤ 2 maximising x + y, is unbounded.
KEY POINT Contest uses: some flow / cut problems are LPs ( 志愿者招募  P3980 is solved both by min-cost flow and
by the simplex method on its dual); duality (max c·x, Ax ≤ b ⇔ min b·y, Aᵀy ≥ c) turns covering problems
into packing problems with the same optimum.
TRAP Floating-point pivots accumulate error: compare with EPS everywhere and prefer the largest-ratio rule
only if cycling is impossible. This version assumes b ≥ 0; with negative b, run the initialisation phase
first.

The	Luogu	problems	for	this	chapter,	a	ladder	through	them,	and	experiments	to	try	yourself.
Key	points	to	memorise
1. LP optimum at a vertex; simplex walks to better neighbours.
2. Entering: positive objective coefficient (Bland: smallest index).
3. Leaving: minimum ratio b_i / a_ie over a_ie > 0; none ⇒ unbounded.
4. b < 0 ⇒ initialisation phase first.
5. Duality: max cx, Ax ≤ b ⇔ min by, Aᵀy ≥ c.
