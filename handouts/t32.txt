32.1 点、线与线段
Orientation;	intersection	with	all	edge	cases.
IDEA Points,	lines	and	segments ( 点和线 ) are all answered with cross products ( 第 13 章 ). orient(a, b, c) = (b
− a) × (c − a) tells whether c is left of, on, or right of the line ab. Two segments AB and CD properly	cross
when C, D lie on opposite sides of AB and A, B on opposite sides of CD; touching or collinear overlaps
happen when an orientation is 0 and the point lies inside the other segment's bounding box.
KEY POINT Distance from a point P to a line AB = |(B − A) × (P − A)| / |B − A|. To a segment: if the projection falls
outside [A, B] (dot products have the wrong sign), the answer is the distance to the nearer endpoint.
Intersection point of two lines: A + t(B − A) with t = ((C − A) × (D − C)) / ((B − A) × (D − C)).
竞 赛 拓 展 专 题  · 拓 展 篇  · 数 学 拓 展
Test segment intersection and point-in-polygon exactly with cross products, sweep the hull with rotating
calipers, intersect half-planes with a deque, and extend the products to circles and three dimensions.

IDEA Polygons ( 多边形 ): area by the shoelace formula ( 第 13 章 ); point	in	polygon by ray casting: shoot a ray
to the right from the point and count how many edges it crosses; odd = inside. Check "on the boundary"
first. Count an edge only if exactly one endpoint is strictly above the ray's line (half-open rule), so a vertex
on the ray is not counted twice.
KEY POINT For a convex polygon, binary search over the fan of triangles from vertex 0 answers in O(log n). The
polygon may be concave for ray casting.

32.3 旋转卡壳
Two	pointers	around	the	hull;	diameter.
IDEA Rotating	calipers ( 旋转卡壳 ): on a convex hull, walk two pointers around it together. For each edge i →
i+1, advance the opposite pointer j while the triangle (i, i+1, j+1) is larger than (i, i+1, j); then j is the
farthest vertex from that edge. Every pointer goes around once: O(n) after the hull.
KEY POINT It gives the diameter (farthest pair, P1452), the minimum width, and the minimum-area enclosing
rectangle (P3187): the rectangle always has a side on a hull edge, so try every edge with three pointers (far
side, left, right).

h[j])); }

32.4 半平面交
Sort	by	angle;	deque;	convex	polygon	intersection.
IDEA Half-plane	intersection ( 半平面交 ): each directed line keeps the region on its left. Sort lines by angle
(keep the innermost of parallel lines), then sweep with a deque: before adding a line, pop lines from the
back (and front) whose last intersection point falls outside it. At the end, trim the back and front against
each other. The remaining lines form the intersection polygon: O(n log n).
KEY POINT Intersection of convex polygons (P4196) = half-plane intersection of all their edges (counter-clockwise, so
the inside is on the left). Use doubles with an EPS for "outside", and be ready for an empty or unbounded
result (add a big bounding box to keep it bounded).

half_plane.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 const double EPS = 1e-9;
5 struct V { double x, y; };
6 V operator+(V a, V b) { return V{a.x + b.x, a.y + b.y}; }
7 V operator-(V a, V b) { return V{a.x - b.x, a.y - b.y}; }
8 V operator*(V a, double t) { return V{a.x * t, a.y * t}; }
9 double cross(V a, V b) { return a.x * b.y - a.y * b.x; }
10 struct L { V p, d; double ang; };                 // keeps the left side of p + t*d
11 V meet(L a, L b) { return a.p + a.d * (cross(b.d, a.p - b.p) / cross(a.d, b.d)); }
12 bool outside(L l, V q) { return cross(l.d, q - l.p) < -EPS; }   // q strictly right of l
13 bool byAngle(const L &a, const L &b) {
14     if (fabs(a.ang - b.ang) > EPS) return a.ang < b.ang;
15     return cross(a.d, b.p - a.p) > 0;             // same direction: inner (more left) line first
16 }
17  
18 int main() {
19     int k;
20     cin >> k;
21     vector<L> ls;
22     for (int t = 0; t < k; t++) {
23         int m; cin >> m;
24         vector<V> poly(m);
25         for (int i = 0; i < m; i++) cin >> poly[i].x >> poly[i].y;
26         for (int i = 0; i < m; i++) {             // counter-clockwise edges
27             V d = poly[(i + 1) % m] - poly[i];
28             ls.push_back(L{poly[i], d, atan2(d.y, d.x)});
29         }
30     }
31     sort(ls.begin(), ls.end(), byAngle);
32     vector<L> u;
33     for (int i = 0; i < int(ls.size()); i++)      // drop the outer copies of parallel lines
34         if (i == 0 || fabs(ls[i].ang - ls[i - 1].ang) > EPS) u.push_back(ls[i]);
35     deque<L> q;
36     for (int i = 0; i < int(u.size()); i++) {
37         while (q.size() >= 2 && outside(u[i], meet(q[q.size() - 1], q[q.size() - 2]))) q.pop_back();
38         while (q.size() >= 2 && outside(u[i], meet(q[0], q[1]))) q.pop_front();
39         q.push_back(u[i]);
40     }
41     while (q.size() >= 3 && outside(q[0], meet(q[q.size() - 1], q[q.size() - 2]))) q.pop_back();
42     while (q.size() >= 3 && outside(q[q.size() - 1], meet(q[0], q[1]))) q.pop_front();
43     double area = 0;
44     if (q.size() >= 3) {
45         vector<V> pts;
46         for (int i = 0; i < int(q.size()); i++) pts.push_back(meet(q[i], q[(i + 1) % q.size()]));
47         for (int i = 0; i < int(pts.size()); i++) area += cross(pts[i], pts[(i + 1) % pts.size()]);
48     }
49     cout << fixed << setprecision(3) << fabs(area) / 2 << "\n";
50     return 0;
51 }

32.5 圆与三维几何
Circle–line;	3D	cross;	triple	product.
IDEA Circles ( 圆 ): a point is inside when its distance to the centre is ≤ r; a line meets a circle when its distance
to the centre ≤ r, and the two points come from the foot of the perpendicular ± √(r² − d²) along the line.
The circumcircle of three points and the minimum enclosing circle were in 第 15 章 .
KEY POINT 3D	geometry ( 三维几何 ): the dot product is a·b = axbx + ayby + azbz; the cross product a × b is a vector
perpendicular to both, with length = the parallelogram area. The triple product (a × b)·c is six times the
signed volume of a tetrahedron, and its sign says which side of the plane through a, b a point lies on: the
3D "orientation" test. The 3D convex hull (P4724) is built from it incrementally; the minimum enclosing
sphere extends the random incremental circle.

32.6 课后习题与实验
The	Luogu	problems	for	this	chapter,	a	ladder	through	them,	and	experiments	to	try	yourself.
Key	points	to	memorise
1. orient(a, b, c) = (b − a) × (c − a): left / on / right.
2. Segments cross: opposite sides both ways, plus collinear-on-segment cases.
3. Point in polygon: boundary first; ray crossings with half-open edges; odd = in.
4. Calipers: advance j while the triangle area grows; O(n) diameter.
5. Half-planes: sort by angle, inner parallel first; deque pops back and front.
6. 3D: cross is a vector; (a × b)·c = 6 × signed tetrahedron volume.
