21.1 整除的基本知识
a	|	b,	remainders,	divisor	pairs,	walking	multiples.
Fact Meaning / rule
a | b ("a divides
b")
b = a·k for some integer k; in code b %
a == 0
a | b and a | c then a | (b + c) and a | (b − c)
(a + b) % m = ((a % m) + (b % m)) % m
(a × b) % m = ((a % m) × (b % m)) % m
(a − b) % m = ((a % m) − (b % m) + m) % m
divisors come in
pairs
d and n / d; one of them ≤ √n
IDEA Divisibility is the heart of number theory
problems. The mod rules let you keep
numbers small: take % m  after every
addition and multiplication and the final
remainder is still right. Division does not
work this way.
KEY POINT Divisors pair up as d and n/d, so trying d
up to √n finds them all ( 第 4 章 ). For "how
many numbers in a list divide x" over
many x, turn it around and walk the
multiples of each value instead.

cross out multiples of 2, 3, … ; green numbers are prime
IDEA A prime has exactly two divisors, 1 and
itself; other numbers above 1 are
composite. Testing one number takes
O(√n). To find all primes up to N, sieve:
for each prime p, cross out its multiples.
Whatever is never crossed out is prime.
KEY POINT Linear	sieve ( 欧拉筛 ): cross out each
composite exactly once, by its smallest
prime factor; O(N). It also gives every
number's smallest prime factor for free.
linear_sieve.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 const int N = 100000005;
5 vector<int> primes;
6 vector<bool> composite(N);
7  
8 int main() {
9     ios::sync_with_stdio(false);
10     cin.tie(nullptr);
11     int n, q;
12     cin >> n >> q;
13     for (int i = 2; i <= n; i++) {
14         if (!composite[i]) primes.push_back(i);
15         for (int j = 0; j < int(primes.size()) && 1LL * i * primes[j] <= n; j++) {
16             composite[i * primes[j]] = true;   // crossed out by its smallest prime
17             if (i % primes[j] == 0) break;     // larger primes are not smallest
18         }
19     }
20     while (q--) {
21         int k;
22         cin >> k;
23         cout << primes[k - 1] << "\n";         // the k-th prime
24     }
25     return 0;
26 }

prime_density.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 int main() {
5     long long L, R;
6     cin >> L >> R;                        // R up to 2^31, R - L up to 10^6
7     int lim = sqrt(double(R)) + 1;
8     vector<bool> small(lim + 1, true);
9     vector<bool> isPrime(R - L + 1, true);   // index x - L
10     for (int p = 2; p <= lim; p++) {
11         if (!small[p]) continue;
12         for (int m = 2 * p; m <= lim; m += p) small[m] = false;
13         long long start = max(1LL * p * p, (L + p - 1) / p * p);
14         for (long long x = start; x <= R; x += p) isPrime[x - L] = false;
15     }
16     int cnt = 0;
17     for (long long x = L; x <= R; x++)
18         if (x >= 2 && isPrime[x - L]) cnt++;
19     cout << cnt << "\n";
20     return 0;
21 }

KEY POINT vector<bool>  stores one bit per entry, so 108 flags fit in about 12 MB (P3383). A huge range [L, R] that is

segmented	sieve (P1835). Remember that 1 is not prime.
21.3 最大公约数与最小公倍数
Euclid,	gcd	×	lcm	=	a	×	b,	pairs	with	a	given	gcd	and	lcm.
IDEA The greatest	common	divisor gcd(a, b) is the largest number dividing both; the least	common
multiple lcm(a, b) is the smallest number both divide. Euclid: gcd(a, b) = gcd(b, a mod b), ending at
gcd(a, 0) = a, in O(log). And gcd(a, b) × lcm(a, b) = a × b.

KEY POINT If gcd(P, Q) = x and lcm(P, Q) = y, then P = x·a and Q = x·b with a·b = y/x and gcd(a, b) = 1, so counting
pairs means counting coprime splits of y/x (P1029). Write a / gcd(a, b) * b , dividing first, so the lcm
does not overflow on the way (P4057). Reducing fractions (P1572) divides top and bottom by their gcd.
21.4 ( 选读 ) 算术基本定理
Unique	prime	factorisation;	counting	and	summing	divisors.
IDEA Fundamental	theorem	of	arithmetic: every integer above 1 is a product of primes in exactly one way, n
= p₁e₁ · p₂e₂ ⋯. Factor by trial division up to √n; whatever is left above 1 is one last prime.

factorize.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 int main() {
5     long long n;
6     cin >> n;
7     long long orig = n, divisors = 1, sigma = 1;
8     cout << orig << " =";
9     bool first = true;
10     for (long long p = 2; p * p <= n; p++) {
11         if (n % p != 0) continue;
12         int e = 0;
13         long long pk = 1, sum = 1;            // sum = 1 + p + ... + p^e
14         while (n % p == 0) { n /= p; e++; pk *= p; sum += pk; }
15         cout << (first ? " " : " * ") << p << "^" << e;
16         first = false;
17         divisors *= (e + 1);
18         sigma *= sum;
19     }
20     if (n > 1) {                              // one prime left over
21         cout << (first ? " " : " * ") << n << "^1";
22         divisors *= 2;
23         sigma *= (1 + n);
24     }
25     cout << "\n" << divisors << " divisors, sum " << sigma << "\n";
26     return 0;
27 }

From n = Π pᵢ^eᵢ Formula
number of divisors Π (eᵢ + 1)
sum of divisors Π (1 + pᵢ + … + pᵢ^eᵢ)
gcd(a, b) each prime to the smaller exponent
lcm(a, b) each prime to the larger exponent
a divides b every exponent in a ≤ the one in b
KEY POINT A divisor of n picks each exponent from 0 to eᵢ independently, so the multiplication principle ( 第 20 章 )
gives Π(eᵢ + 1) divisors: 360 = 2³·3²·5 has 4·3·2 = 24. "How long until cells divide evenly into tubes"
compares exponents of the same primes (P1069); the divisor sum of ab mod 9901 uses the sum formula
with fast powers (P1593).

Key	points	to	memorise
1. a | b ⇔ b	%	a	==	0; mod after every + and ×, never for ÷.
2. Negative-safe subtraction: ((a	−	b)	%	m	+	m)	%	m.
3. Divisors pair as d, n/d: search to √n.
4. Many "who divides x": walk multiples, total ≈ M ln M.
5. Σ_{i≤n} d(i) = Σ ⌊n / i⌋.
6. Sieve of Eratosthenes O(N log log N); linear sieve O(N) with smallest prime factors.
7. Segmented sieve: primes ≤ √R, start at max(p², first multiple ≥ L); 1 is not prime.
8. Euclid: gcd(a, b) = gcd(b, a % b); lcm	=	a	/	gcd	·	b.
9. n = Π pᵢ^eᵢ: Π(eᵢ+1) divisors; gcd takes min exponents, lcm max.
