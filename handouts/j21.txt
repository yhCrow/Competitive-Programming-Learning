21.1 事件
Complements,	independence,	conditional	probability.
IDEA An event ( 事件 ) is a set of outcomes. P(A) is its probability; P(not A) = 1 − P(A); for disjoint events
probabilities add; for independent events they multiply. The conditional	probability P(A | B) = P(A and
B) / P(B) is the probability of A once we know B happened.
KEY POINT Conditional problems become counting: restrict to the outcomes where B holds, and measure how much
of that weight also has A. With n ≤ 20 independent people you can simply enumerate all 2ⁿ outcomes as
bitmasks ( 第 17 章 ).
given.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 int main() {
5     int n, r, tc = 0;
6     while (cin >> n >> r && n) {
7         vector<double> p(n), bought(n, 0);
8         for (int i = 0; i < n; i++) cin >> p[i];
9         double total = 0;                                    // P(exactly r people buy)
10         for (int S = 0; S < (1 << n); S++) {
11             if (__builtin_popcount(S) != r) continue;        // only outcomes where B holds
12             double w = 1;
13             for (int i = 0; i < n; i++) w *= (S >> i & 1) ? p[i] : 1 - p[i];
14             total += w;
15             for (int i = 0; i < n; i++) if (S >> i & 1) bought[i] += w;   // A_i and B
16         }
17         cout << "Case " << ++tc << ":\n";
18         for (int i = 0; i < n; i++) cout << fixed << setprecision(6) << bought[i] / total << "\n";
19     }
20     return 0;
21 }

IDEA Probability | Given (UVA11181): each friend buys independently with probability pi; we are told exactly r
bought. P(i bought | r bought) = P(i bought and exactly r bought) / P(exactly r bought).
KEY POINT Exactly two of three buy with weight 0.1·0.2·0.7 + 0.1·0.8·0.3 + 0.9·0.2·0.3 = 0.092; friend 1 is in the first
two: (0.014 + 0.024) / 0.092 ≈ 0.413.
21.2 概率模型
Classical	model;	write	it	down	first.
IDEA A probability	model ( 概率模型 ) fixes what is random and how. Classical: finitely many equally likely
outcomes, P = good / all. Geometric: a point uniform in a region, P = good area / total area. Most contest
problems are classical: count, then divide.
KEY POINT Write the model down before computing: "question i is answered with the correct answer of question i −
1, which is uniform among ai−1 options". A wrong model gives a confident wrong answer.
shifted_answers.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 int main() {
5     int n;
6     cin >> n;
7     vector<int> a(n);
8     for (int i = 0; i < n; i++) cin >> a[i];        // number of options per question
9     double expected = 0;
10     for (int i = 0; i < n; i++) {
11         int prev = a[(i - 1 + n) % n];              // answer copied from the previous question
12         expected += 1.0 / max(a[i], prev);          // P(both uniform answers agree)
13     }
14     cout << fixed << setprecision(3) << expected << "\n";
15     return 0;
16 }

IDEA Shifted answers (P1297): question i has ai options and its true answer is uniform; the written answer is
the true answer of question i − 1. Both are uniform and independent, and they can only agree on the
smaller range: P = min / (ai·ai−1) = 1 / max(ai, ai−1).
KEY POINT Expected number correct = Σ P(question i correct): linearity of expectation (21.3) lets you add the per-
question probabilities even though the questions are not independent. The real problem generates a with a
formula; the idea is unchanged.

IDEA The expected	value ( 数学期望 ) E[X] =
Σ x·P(X = x). Its most useful property:
linearity, E[X + Y] = E[X] + E[Y] for any
X, Y, even dependent ones. So split the
quantity into small pieces (indicators: 1
if something happens, 0 otherwise) and
add the probabilities.
KEY POINT Game on a tree (CF280C): each step
removes a random remaining node with
its subtree; expected number of steps?
Steps = Σ [node i is picked itself]. Node i
is picked itself exactly when it is the
first chosen among its depth(i)
ancestors-or-self, each equally likely: E
= Σ 1 / depth(i).
tree_game.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 const int N = 100005;
5 vector<int> g[N];
6 int dep[N];
7  
8 int main() {
9     int n;
10     cin >> n;
11     for (int i = 1; i < n; i++) {
12         int a, b;
13         cin >> a >> b;
14         g[a].push_back(b);
15         g[b].push_back(a);
16     }
17     queue<int> q;                         // BFS for depths: no deep recursion
18     dep[1] = 1; q.push(1);
19     double ans = 0;
20     while (!q.empty()) {
21         int u = q.front();
22         q.pop();
23         ans += 1.0 / dep[u];              // indicator: u is picked before its ancestors
24         for (int k = 0; k < int(g[u].size()); k++) {
25             int v = g[u][k];
26             if (!dep[v]) { dep[v] = dep[u] + 1; q.push(v); }
27         }
28     }
29     cout << fixed << setprecision(6) << ans << "\n";
30     return 0;
31 }

TRAP E[L²] ≠ (E[L])². Squares and products of random variables need their own expectations; only sums split
freely.
KEY POINT Expectation DPs: the frog on a DAG (P4316, 第 16 章 ) fills f backwards from the end; changing classrooms
(P1850) is a DP over (class, requests used, last request made?) where each step adds expected walking
distances from Floyd. Write E as a recurrence over what is still to come, not over what has happened.
21.4 课后习题与实验
The	Luogu	problems	for	this	chapter,	a	ladder	through	them,	and	experiments	to	try	yourself.
Key	points	to	memorise
1. P(not A) = 1 − P(A); independent: multiply; disjoint: add.
2. P(A | B) = P(A and B) / P(B): restrict to B, then measure A.
3. Classical model: good / all; write the model down first.
4. Linearity: E[X + Y] = E[X] + E[Y], always. Split into indicators.
5. Tree game: node removed itself with probability 1 / depth.
6. Combo²: add 2L + 1 per hit; keep E[L].
7. Combo³: add 3L² + 3L + 1; keep E[L] and E[L²].
8. E[L²] ≠ E[L]²; expectation DPs run backwards over what is still to come.
