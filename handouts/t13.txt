13.1 向量与凸包
Cross	product	signs;	shoelace	area;	Andrew's	algorithm.
a
b
a × b > 0
a × b = a.x·b.y − a.y·b.x
> 0: b is to the left
= 0: same line
< 0: b is to the right
IDEA Computational geometry ( 计算几何 )
starts with vectors and two products.
The dot	product a·b = axbx + ayby
measures the angle (0 at right angles).
The cross	product a × b = axby − aybx is
twice the signed triangle area: positive
when b turns left from a.
KEY POINT Almost every test is a cross-product
sign: which side of a line a point lies on,
whether two segments cross, whether a
polygon turns left. Polygon area = ½ |Σ
pi × pi+1| (the shoelace formula). Use
integers when inputs are integers; with
doubles compare against a small EPS.

convex_hull.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 struct P { double x, y; };
5 P operator-(P a, P b) { return P{a.x - b.x, a.y - b.y}; }
6 double cross(P a, P b) { return a.x * b.y - a.y * b.x; }
7 double dist(P a, P b) { return sqrt((a.x - b.x) * (a.x - b.x) + (a.y - b.y) * (a.y - b.y)); }
8 bool byXY(P a, P b) { return a.x < b.x || (a.x == b.x && a.y < b.y); }
9  
10 int main() {
11     int n;
12     cin >> n;
13     vector<P> p(n);
14     for (int i = 0; i < n; i++) cin >> p[i].x >> p[i].y;
15     sort(p.begin(), p.end(), byXY);
16     vector<P> h;                                       // Andrew's monotone chain
17     for (int pass = 0; pass < 2; pass++) {             // lower hull, then upper hull
18         int start = h.size();
19         for (int i = 0; i < n; i++) {
20             P c = pass == 0 ? p[i] : p[n - 1 - i];
21             while (int(h.size()) >= start + 2 && cross(h.back() - h[h.size() - 2], c - h.back()) <= 0)
22                 h.pop_back();                          // not a left turn: drop the middle point
23             h.push_back(c);
24         }
25         h.pop_back();                                  // the last point starts the other chain
26     }
27     double per = 0;
28     for (int i = 0; i < int(h.size()); i++) per += dist(h[i], h[(i + 1) % h.size()]);
29     double area = 0;
30     for (int i = 0; i < int(h.size()); i++) area += cross(h[i], h[(i + 1) % h.size()]);
31     cout << fixed << setprecision(2) << per << "\n" << fabs(area) / 2 << "\n";
32     return 0;
33 }

KEY POINT Convex hull (P2742): sort points by x, build the lower chain left to right and the upper chain right to left,
popping while the last turn is not to the left. O(n log n). The hull here is the triangle (4, 8), (7, 8), (4, 12):
perimeter 3 + 5 + 4 = 12, area 6.
TRAP Use ≤ 0 in the pop condition to drop collinear points (or < 0 to keep them, if the problem wants them).
Duplicate points and n ≤ 2 are the classic edge cases.
13.2 平面最近点对
Sweep	with	a	set	ordered	by	y.
IDEA Closest	pair	of	points ( 平面最近点对 ): sort by x and sweep. Keep a set of the points within the current
best distance h to the left, ordered by y; for each new point only those with |y − yp| < h can be closer, and
there are only a few of them. O(n log n).

closest_pair.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 int main() {
5     int n;
6     cin >> n;
7     vector<pair<double, double>> p(n);                       // (x, y)
8     for (int i = 0; i < n; i++) cin >> p[i].first >> p[i].second;
9     sort(p.begin(), p.end());
10     set<pair<double, double>> active;                        // (y, x) of points with x within h
11     double h = 1e18;
12     int left = 0;
13     for (int i = 0; i < n; i++) {
14         while (left < i && p[i].first - p[left].first >= h) {  // too far to the left
15             active.erase(make_pair(p[left].second, p[left].first));
16             left++;
17         }
18         auto it = active.lower_bound(make_pair(p[i].second - h, -1e18));
19         for (; it != active.end() && it->first < p[i].second + h; it++) {
20             double dx = p[i].first - it->second, dy = p[i].second - it->first;
21             h = min(h, sqrt(dx * dx + dy * dy));
22         }
23         active.insert(make_pair(p[i].second, p[i].first));
24     }
25     cout << fixed << setprecision(4) << h << "\n";
26     return 0;
27 }

13.3 课后习题与实验
The	Luogu	problems	for	this	chapter,	a	ladder	through	them,	and	experiments	to	try	yourself.
Key	points	to	memorise
1. Dot: angle; cross a × b: twice the signed area; > 0 means b turns left.
2. Area = ½ |Σ pᵢ × pᵢ₊₁|.
3. Hull: sort by x, lower then upper chain, pop while not a left turn.
4. Closest pair: sweep by x, set by y, only |dy| < h matters.
5. Integers when possible; with doubles compare using EPS.
