5.3.2 Comparing	pairs	and	scanning	ranges
Two	indices,	or	a	window	that	slides.
self · ✓ ·
dup self · ✓
dup dup self ·
dup dup dup self
3 9 4 8
3

IDEA Every element against every other: outer i , inner j = i + 1 . That
visits the upper-right triangle: each pair exactly once, never an
element with itself.
TRAP Starting the inner loop at j = 0  counts each pair twice and adds
every self-pair that passes: wrong	=	2	×	correct	+	n. On 3 9 4 8
with |diff| ≤ 1: 2 becomes 8.
KEY POINT n(n − 1) / 2 pairs, O(n²): fine up to n ≈ 5000.

5.3.6 Transforms	and	compression
Grids	changed	as	a	whole:	rotate,	mirror,	encode.
@ - @
- - -
@ @ -
90°
@ - @
@ - -
- - @
column 0 of A, bottom to top = row 0 of B
Transform (0-based, n × n) Rule: b[?][?] = a[i][j]
Rotate 90° clockwise b[j][n-1-i]
Rotate 180° b[n-1-i][n-1-j]
Rotate 270° clockwise b[n-1-j][i]
Mirror left ↔ right b[i][n-1-j]
Mirror top ↔ bottom b[n-1-i][j]
Transpose b[j][i]
IDEA Write each transform as "where does cell (i, j) go?".
Then 180° = 90° twice, and combinations are
transforms applied one after another.

C C LANGUAGE · ADDITIONAL INFORMATION
In C, a grid of characters is a 2D char  array, char g[N][N] , and each row is read with cin >> g[i]  or scanf("%s",
g[i]) . Leave one extra column for the hidden \0  that ends each row. A whole array cannot be assigned with = , so
copying uses memcpy(dst, src, sizeof src) .

Key	points	to	memorise
1. int	a[N] has a[0] … a[N−1]; size with a margin; big arrays go global.
2. Global arrays start at 0, local ones hold garbage; set values with =	{} or fill.
3. (C) memset fills bytes: only 0 and −1 are safe; C grids are char	g[N][N], copied with memcpy.
4. Pick 0-based or 1-based once; 1-based leaves index 0 free as padding.
5. Record: mark[p] = 1 handles overlaps; counter: cnt[v]++ tallies values.
6. Negative values: cnt[v	+	offset]; −100..100 needs 201 boxes.
7. Toggle with ^=	1; counting by value also sorts.
8. All pairs once: for	i,	for	j	=	i	+	1; from j = 0 gives 2 × correct + n.
9. Sliding window: s	+=	a[i]	−	a[i	−	m], O(n) instead of O(n·m).
10. a[i][j] = row i, column j; rows outside, columns inside.
11. Recurrence from the row above reads row i	−	1; zero padding removes edge cases.
12. dx/dy arrays for moves; turn right with (d	+	1)	%	4; check bounds first.
13. Rotate 90° clockwise (0-based): b[j][n−1−i]	=	a[i][j]; never in place.
14. Run-length: runs alternate and start with a run of 0s.
