15.1 数组
vector,	direct	access,	and	sparse	storage	with	map.
IDEA A linear	list keeps items in a row, each with one item before it and one after. The four structures of this
chapter store such a row differently, and each makes different operations cheap. Choose by the operations
the problem needs most.
Structure Read the i-th Add / remove at the end Add / remove at the front Insert / delete in the middle
array / vector O(1) O(1) (push_back) O(n) O(n): shift everything after
stack top only O(1) at the top — —
queue front only add at the back O(1) remove at the front O(1) —
linked list O(n): walk O(1) O(1) O(1) once you are there

IDEA 105 lockers with up to 105 slots each would need 1010 boxes, but only q of them are ever used. A map
stores only the used (key, value) pairs, each lookup costs O(log q) (P3613).
KEY POINT map[key]  creates the key with value 0 if it is missing; that is exactly "empty slot" here. Use
map.count(key)  when you must not create it.
15.2 栈
Last	in,	first	out:	postfix	expressions,	brackets,	stack	sequences.
3
5
2
push / pop
at the top
IDEA A stack is last in, first out (LIFO): you only touch the top, like a
pile of plates. push  puts on top, pop  removes the top, top
reads it; all O(1).
KEY POINT Use a stack when the most recent unfinished thing must be dealt
with first: matching brackets, evaluating expressions, undoing
steps, and turning recursion into a loop.

postfix.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 int main() {
5     string s;
6     cin >> s;                         // numbers end with '.', '@' ends all
7     stack<long long> st;
8     long long num = 0;
9     for (int i = 0; i < int(s.size()) && s[i] != '@'; i++) {
10         char ch = s[i];
11         if ('0' <= ch && ch <= '9') num = num * 10 + (ch - '0');
12         else if (ch == '.') { st.push(num); num = 0; }   // a number ends
13         else {
14             long long b = st.top(); st.pop();            // right operand
15             long long a = st.top(); st.pop();            // left operand
16             if (ch == '+') st.push(a + b);
17             if (ch == '-') st.push(a - b);
18             if (ch == '*') st.push(a * b);
19             if (ch == '/') st.push(a / b);
20         }
21     }
22     cout << st.top() << "\n";
23     return 0;
24 }
INPUT
3.5.2.-*7.+@
OUTPUT
16
IDEA In postfix ( 后缀 ) notation the operator comes after its two operands, so no brackets are needed. Push
numbers; on an operator, pop two, combine, push the result. The last value on the stack is the answer
(P1449).
TRAP The first pop is the right operand. For -  and /  the order matters: 5 2 − means 5 − 2.

KEY POINT Brackets: each closer must match the most recent unmatched opener, which is the stack top; at the end
nothing may be left (P1241 adds rules for repairing). Stack sequences: simulate with a real stack, popping
whenever the top is the next value to pop; if anything is left, the order was impossible (P4387).
15.3 队列
First	in,	first	out:	Josephus	circle	and	a	fixed-size	memory.
4 7 1 9out ← ← in
front pops first, new items join at the back
IDEA A queue is first in, first out (FIFO), like a line at a
counter. push  joins at the back, pop  leaves from the
front, front  reads the first; all O(1).
KEY POINT BFS ( 第 14 章 ) is a queue. deque  allows push and
pop at both ends, useful for sliding windows such as
"ships in the last 24 hours" (P2058).

translation_cache.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 bool inMemory[1005];
5  
6 int main() {
7     int capacity, n;
8     cin >> capacity >> n;
9     queue<int> mem;                        // oldest word at the front
10     int lookups = 0;
11     for (int i = 0; i < n; i++) {
12         int w;
13         cin >> w;
14         if (inMemory[w]) continue;         // already stored
15         lookups++;                         // look it up in the dictionary
16         if (int(mem.size()) == capacity) { // full: forget the oldest
17             inMemory[mem.front()] = false;
18             mem.pop();
19         }
20         mem.push(w);
21         inMemory[w] = true;
22     }
23     cout << lookups << "\n";
24     return 0;
25 }

3 7
1 2 1 5 4 4 1
OUTPUT

KEY POINT A circle of people counting off becomes a queue: moving the front to the back is "pass to the next person"
(P1996). A memory that forgets the oldest item is a queue plus a marking array that answers "is it stored?"
in O(1) (P1540).

15.4 链表
Links	in	L[]	and	R[]	arrays:	O(1)	insert	and	delete.
head 2 4 1
R[x] = right neighbour, L[x] = left neighbour
IDEA A linked	list stores, for every item, who
comes next (and, doubly linked, who
comes before). Inserting or deleting
only rewires a few links: O(1), with no
shifting. The price: reaching the i-th item
means walking from the head, O(n).
KEY POINT In contests, keep the links in two arrays,
L[x]  and R[x] , indexed by the item
itself; node 0 is a fixed head that is
never deleted, so the first item needs no
special case.

queue_arrange.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 int L[100005], R[100005];
5 bool gone[100005];
6  
7 void insertRight(int k, int x) {        // put x just right of k
8     R[x] = R[k]; L[x] = k;
9     L[R[k]] = x; R[k] = x;
10 }
11  
12 int main() {
13     int n;
14     cin >> n;
15     R[0] = 0; L[0] = 0;                 // empty circle: head links to itself
16     insertRight(0, 1);                  // student 1 stands alone
17     for (int i = 2; i <= n; i++) {
18         int k, p;
19         cin >> k >> p;                  // p = 0: left of k, p = 1: right of k
20         if (p == 0) insertRight(L[k], i);
21         else insertRight(k, i);
22     }
23     int m;
24     cin >> m;
25     while (m--) {
26         int x;
27         cin >> x;
28         if (gone[x]) continue;          // removing twice does nothing
29         gone[x] = true;
30         R[L[x]] = R[x];                 // unlink x: its neighbours
31         L[R[x]] = L[x];                 // now point at each other
32     }
33     for (int x = R[0]; x != 0; x = R[x]) cout << x << " ";
34     cout << "\n";
35     return 0;
36 }

KEY POINT "Insert left of k" is "insert right of k's left neighbour", so one insert function is enough. Delete by linking
the two neighbours to each other. Walking R[]  from the head prints the final order (P1160).
Step Links changed
insert x right of k R[x], L[x], L[R[k]], R[k]
delete x R[L[x]], L[R[x]]
walk x = R[x] until back at head 0
TRAP Rewire in the right order: read R[k]  into
x's links before overwriting R[k] .
Drawing the boxes and arrows on paper
first prevents most linked-list bugs.
KEY POINT For "closest earlier value" questions such
as daily turnover (P2234), a sorted set
with lower_bound  gives each answer in
O(log n) ( 集合 , 第 17 章 ).

15.5 课后习题与实验
The	Luogu	problems	for	this	chapter,	a	ladder	through	them,	and	experiments	to	try	yourself.
Key	points	to	memorise
1. Pick the structure by its cheap operations: index → array; ends → stack/queue; middle → linked list.
2. vector: push_back O(1), v[i] O(1), insert/erase in the middle O(n).
3. Sparse huge index space → map; map[key] creates a 0 if missing.
4. stack: push, pop, top; LIFO; brackets, postfix, undo.
5. Postfix: push numbers; on an operator pop b then a, push a op b.
6. Brackets: closer must match the top; stack must end empty.
7. queue: push, pop, front; FIFO; BFS, circles, caches.
8. Josephus: move the front to the back m − 1 times, then remove.
9. Linked list in arrays: L[x], R[x], head node 0; insert/delete O(1).
10. Insert-left of k = insert-right of L[k]; delete = link the two neighbours.
