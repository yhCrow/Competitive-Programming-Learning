7.3 递归函数
Base	case,	smaller	call,	call	stack,	and	memoisation.
fact(3) = 3 × fact(2)
fact(2) = 2 × fact(1)
fact(1) = 1 (base)
calls
results return upward: 1 → 2 → 6
IDEA Every recursive function has a base	case that answers
directly, and a recursive	case that calls itself on a
smaller input and combines the result. Each call waits
on a stack until the call it made returns.
TRAP No base case, or a step that does not shrink the input,
means infinite recursion: the program crashes with a
stack overflow. Very deep recursion (around 105–106
levels) can crash too.

pardon.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 int g[1030][1030];
5  
6 // square of side s with top-left corner (r, c)
7 void solve(int r, int c, int s) {
8     if (s == 1) return;                       // base case
9     int h = s / 2;
10     for (int i = 0; i < h; i++)               // top-left quarter: 0
11         for (int j = 0; j < h; j++) g[r + i][c + j] = 0;
12     solve(r, c + h, h);                       // the other three
13     solve(r + h, c, h);                       // quarters repeat the
14     solve(r + h, c + h, h);                   // same rule, smaller
15 }
16  
17 int main() {
18     int n;
19     cin >> n;
20     int s = 1 << n;                           // 2^n
21     for (int i = 0; i < s; i++)
22         for (int j = 0; j < s; j++) g[i][j] = 1;
23     solve(0, 0, s);
24     for (int i = 0; i < s; i++) {
25         for (int j = 0; j < s; j++) cout << g[i][j] << " ";
26         cout << "\n";
27     }
28     return 0;
29 }

2
OUTPUT

0 0 1 1 
0 1 0 1 
1 1 1 1
IDEA Split the square into four quarters: one is handled directly, the other three are the same problem at half
size. The function only describes one level; recursion repeats it down to size 1 (P5461).

7.3.2 When	recursion	repeats	work:	memoisation
fib_memo.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 long long memo[95];                  // 0 = not computed yet
5  
6 long long fib(int n) {
7     if (n <= 2) return 1;
8     if (memo[n] != 0) return memo[n];  // already known
9     return memo[n] = fib(n - 1) + fib(n - 2);
10 }
11  
12 int main() {
13     int n;
14     cin >> n;
15     cout << fib(n) << "\n";
16     return 0;
17 }
INPUT 1
50
OUTPUT 1
12586269025
INPUT 2
90
OUTPUT 2
2880067194370816120
TRAP Plain fib(n - 1) + fib(n - 2)  recomputes the same values again and again: about 2n calls, hopeless
for n = 50.
KEY POINT Store each result the first time it is computed and return it straight away next time. Now each fib(k) is
computed once: O(n). This "remember results" idea is the seed of dynamic programming.
KEY POINT Some answers need no recursion at all: the sum over all subsets of a set is (sum of elements) × 2n−1,
because each element appears in half of the subsets (P2415).
7.4 结构体的使用
Group	fields,	member	functions,	arrays	of	structs,	and	sorting	them.

s.english 4 s.total() 169
IDEA A struct  is a new type made of named fields. One Student
carries a name and three scores together, so sorting or picking
the best student moves the whole record at once.
KEY POINT Access fields with a dot: s.name . A struct can also hold
functions (member	functions) that use its fields, such as
s.total() . An array of structs, Student a[1005] , is a table
with one row per student.

1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 struct Student {
5     string name;
6     int score;
7 };
8  
9 // true if x must come before y
10 bool cmp(const Student &x, const Student &y) {
11     if (x.score != y.score) return x.score > y.score;  // high first
12     return x.name < y.name;                            // then A-Z
13 }
14  
15 Student a[1005];
16  
17 int main() {
18     int n;
19     cin >> n;
20     for (int i = 0; i < n; i++) cin >> a[i].name >> a[i].score;
21     sort(a, a + n, cmp);
22     for (int i = 0; i < n; i++)
23         cout << a[i].name << " " << a[i].score << "\n";
24     return 0;
25 }
INPUT
4
bob 240
amy 240
cat 300
dan 180
OUTPUT
cat 300
amy 240
bob 240
dan 180
IDEA sort(a, a + n, cmp)  calls cmp(x, y)  to ask "must x come before y?". Compare the main key first; only
when it ties, compare the next key.
TRAP cmp  must be a strict order: return false  when x and y are equal. Writing >=  instead of >  can crash
sort .
KEY POINT Alternative: give the struct an operator<  and call plain sort(a, a + n) . For one-off orders a lambda
works too: sort(a, a + n, [](const Student &x, const Student &y) { return x.score >
y.score; }) .
C C LANGUAGE · ADDITIONAL INFORMATION
C has no references. To change the caller's variable, C passes its address with &x  and the function works through a
pointer with * . C++ code still meets this in older solutions.
A C struct has no member functions, and in C you must write struct Student s;  (or use typedef ). Sorting in C uses
qsort  with a comparison that returns a negative, zero or positive int .

7.5 课后习题与实验
The	Luogu	problems	for	this	chapter,	a	ladder	through	them,	and	experiments	to	try	yourself.
Key	points	to	memorise
1. A function = return type, name, parameters, body; void returns nothing.
2. Define or declare a function above the code that calls it.
3. Every path of a non-void function must return a value.
4. Parameters are copies; add & to change the caller's variable or return several results.
5. Pass big objects as const	T	&; arrays are never copied, so pass n too.
6. Locals start as garbage and hide globals of the same name.
7. Write tested helpers once: isPrime, isLeap, gcd; return as soon as the answer is known.
8. Recursion = base	case + a call on a smaller input; no base case → stack overflow.
9. Recomputed recursion (fib) is exponential; memoise results to make it linear.
10. A struct groups fields; access with s.field; member functions like s.total().
11. Best record: compare with > to keep the first among ties.
12. Sort structs with cmp(x,	y) = "x before y": main key first, then tie-breaks; never >=.
13. Keep scores exact: score	*	6	/	5, not score * 1.2.
14. (C) C passes pointers (&x, *p) instead of references, and sorts with qsort.
