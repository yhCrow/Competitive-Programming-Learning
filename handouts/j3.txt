3.1 归并排序与快速幂
Merge	sort	with	inversion	counting;	a^b	in	O(log	b).
5 4 2 6 3 1
5 4 2 → 2 4 5 6 3 1 → 1 3 6
merge → 1 2 3 4 5 6
IDEA Divide	and	conquer ( 分治 ): split the
problem into halves, solve each half
recursively, then combine the two answers. If
combining costs O(n), the whole thing costs
O(n log n): there are log n levels, each doing
O(n) work.
KEY POINT Merge sort is the model: sort both halves,
then merge two sorted lists. Anything that can
be counted while merging, such as
inversions, comes for free.
深 入 浅 出 程 序 设 计 竞 赛  · 进 阶 篇  · 第 1 部 分  进 阶 技 巧 与 思 想

inversions.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 int a[500005], tmp[500005];
5 long long inv = 0;
6  
7 void mergeSort(int l, int r) {             // sorts a[l..r]
8     if (l >= r) return;
9     int m = (l + r) / 2;
10     mergeSort(l, m);
11     mergeSort(m + 1, r);
12     int i = l, j = m + 1, k = l;
13     while (i <= m && j <= r) {
14         if (a[i] <= a[j]) tmp[k++] = a[i++];
15         else { tmp[k++] = a[j++]; inv += m - i + 1; }   // a[i..m] all > a[j]
16     }
17     while (i <= m) tmp[k++] = a[i++];
18     while (j <= r) tmp[k++] = a[j++];
19     for (int t = l; t <= r; t++) a[t] = tmp[t];
20 }
21  
22 int main() {
23     ios::sync_with_stdio(false);
24     cin.tie(nullptr);
25     int n;
26     cin >> n;
27     for (int i = 0; i < n; i++) cin >> a[i];
28     mergeSort(0, n - 1);
29     cout << inv << "\n";
30     return 0;
31 }

KEY POINT When a[j] from the right half is placed before a[i] from the left half, it is smaller than every remaining
a[i..m]: that is m − i + 1 inversions at once (P1908). Use long long : n = 5 × 10⁵ can give 1.25 × 10¹¹
inversions. Two rows of matches need as many adjacent swaps as there are inversions after matching
ranks (P1966).

fast_power.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 long long power(long long a, long long b, long long p) {
5     long long res = 1 % p;
6     a %= p;
7     while (b > 0) {
8         if (b & 1) res = res * a % p;   // this bit of b is 1
9         a = a * a % p;                   // a, a^2, a^4, a^8, ...
10         b >>= 1;
11     }
12     return res;
13 }
14  
15 int main() {
16     long long a, b, p;
17     cin >> a >> b >> p;
18     cout << a << "^" << b << " mod " << p << "=" << power(a, b, p) << "\n";
19     return 0;
20 }
INPUT 1
2 10 9
OUTPUT 1
2^10 mod 9=7
INPUT 2
3 0 1
OUTPUT 2
3^0 mod 1=0
IDEA ab by multiplying b times is O(b), hopeless for b = 10⁹. Write b in binary: ab is the product of a2ᵏ over the
1-bits of b, and a2ᵏ comes from squaring. O(log b) multiplications (P1226).
TRAP Take % p  after every multiplication, and keep values in long long  so a product of two numbers below p
(up to about 3 × 10⁹) fits. Start from 1 % p , so p = 1 gives 0. With big numbers instead of mod, the same
loop computes 2ᴾ (P1045).
3.2 其他序列上的分治
Answers	left,	right,	or	crossing	the	middle;	closest	pair	of	points.
IDEA Many sequence problems split the same way: the answer lies entirely in the left half, entirely in the right
half, or crosses the middle. Recursion handles the first two; only the crossing case needs new code, and it
usually has a simple shape because it must touch the middle.

max_subarray_dc.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 long long a[200005];
5  
6 long long best(int l, int r) {
7     if (l == r) return a[l];
8     int m = (l + r) / 2;
9     long long res = max(best(l, m), best(m + 1, r));   // inside one half
10     long long s = 0, leftBest = LLONG_MIN, rightBest = LLONG_MIN;
11     for (int i = m; i >= l; i--) { s += a[i]; leftBest = max(leftBest, s); }
12     s = 0;
13     for (int i = m + 1; i <= r; i++) { s += a[i]; rightBest = max(rightBest, s); }
14     return max(res, leftBest + rightBest);              // crossing the middle
15 }
16  
17 int main() {
18     int n;
19     cin >> n;
20     for (int i = 0; i < n; i++) cin >> a[i];
21     cout << best(0, n - 1) << "\n";
22     return 0;
23 }

2 -4 3 -1 2 -4 3

KEY POINT A crossing subarray = (best sum ending at m, going left) + (best sum starting at m + 1, going right). Two
linear scans per level: O(n log n). The O(n) method of 第 1 章  is faster, but this pattern carries over to
problems that have no simple scan (P1115).

closest_pair.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 struct P { double x, y; };
5 P p[10005];
6  
7 double dist(P a, P b) { return sqrt((a.x - b.x) * (a.x - b.x) + (a.y - b.y) * (a.y - b.y)); }
8  
9 double solve(int l, int r) {              // p[l..r] sorted by x
10     if (r - l <= 2) {                     // tiny: try all pairs
11         double d = 1e18;
12         for (int i = l; i <= r; i++)
13             for (int j = i + 1; j <= r; j++) d = min(d, dist(p[i], p[j]));
14         return d;
15     }
16     int m = (l + r) / 2;
17     double midX = p[m].x;
18     double d = min(solve(l, m), solve(m + 1, r));
19     vector<P> strip;                      // points within d of the middle line
20     for (int i = l; i <= r; i++)
21         if (fabs(p[i].x - midX) < d) strip.push_back(p[i]);
22     sort(strip.begin(), strip.end(), [](const P &a, const P &b) { return a.y < b.y; });
23     for (int i = 0; i < int(strip.size()); i++)
24         for (int j = i + 1; j < int(strip.size()) && strip[j].y - strip[i].y < d; j++)
25             d = min(d, dist(strip[i], strip[j]));   // only a few j per i
26     return d;
27 }
28  
29 int main() {
30     int n;
31     cin >> n;
32     for (int i = 0; i < n; i++) cin >> p[i].x >> p[i].y;
33     sort(p, p + n, [](const P &a, const P &b) { return a.x < b.x; });
34     cout << fixed << setprecision(4) << solve(0, n - 1) << "\n";
35     return 0;
36 }

KEY POINT Closest pair of points: after solving both halves with best distance d, a crossing pair must lie within d of
the dividing line, and sorted by y each point only needs to be compared with the next few points closer
than d vertically: O(n log² n) (P1257). Sums over all pairs such as MooFest (P2345) are also counted
across the middle while merging.

IDEA Binary	lifting ( 倍增 ): precompute the
answer for blocks of length 1, 2, 4, 8, …;
any length is a sum of powers of two, so a
few precomputed blocks cover it. A
sparse	table (ST 表 ) stores mx[k][i] =
max of a[i … i + 2ᵏ − 1].
KEY POINT A range max/min query [l, r] is covered
by two overlapping blocks of length 2ᵏ,
with k = ⌊log₂(r − l + 1)⌋: one starting at l,
one ending at r. Overlap is harmless for
max and min, so each query is O(1) after
O(n log n) preparation.
sparse_table.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 int mx[17][50005], mn[17][50005], lg[50005];
5  
6 int main() {
7     ios::sync_with_stdio(false);
8     cin.tie(nullptr);
9     int n, q;
10     cin >> n >> q;
11     for (int i = 1; i <= n; i++) { cin >> mx[0][i]; mn[0][i] = mx[0][i]; }
12     for (int i = 2; i <= n; i++) lg[i] = lg[i / 2] + 1;          // floor(log2 i)
13     for (int k = 1; (1 << k) <= n; k++)
14         for (int i = 1; i + (1 << k) - 1 <= n; i++) {
15             mx[k][i] = max(mx[k - 1][i], mx[k - 1][i + (1 << (k - 1))]);   // two halves
16             mn[k][i] = min(mn[k - 1][i], mn[k - 1][i + (1 << (k - 1))]);
17         }
18     while (q--) {
19         int l, r;
20         cin >> l >> r;
21         int k = lg[r - l + 1];
22         int hi = max(mx[k][l], mx[k][r - (1 << k) + 1]);   // two overlapping blocks
23         int lo = min(mn[k][l], mn[k][r - (1 << k) + 1]);
24         cout << hi - lo << "\n";
25     }
26     return 0;
27 }

KEY POINT A block of length 2ᵏ is two blocks of length 2ᵏ⁻¹, so each table row comes from the row before. The tallest
minus the shortest cow in a range (P2880) and the most loyal (smallest) account in a range (P1816) are
direct ST-table queries. Sums do not work with overlapping blocks; use prefix sums for those.
3.3.1 Jumping	2ᵏ	steps	at	a	time
jump_steps.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 int nxt[61][100005];                      // nxt[k][i]: where 2^k steps from i lead
5  
6 int main() {
7     int n, q;
8     cin >> n >> q;
9     for (int i = 1; i <= n; i++) cin >> nxt[0][i];
10     for (int k = 1; k <= 60; k++)
11         for (int i = 1; i <= n; i++) nxt[k][i] = nxt[k - 1][nxt[k - 1][i]];   // 2^(k-1) twice
12     while (q--) {
13         int s;
14         long long t;
15         cin >> s >> t;
16         for (int k = 0; k <= 60; k++)
17             if (t >> k & 1) s = nxt[k][s];      // use the 1-bits of t
18         cout << s << "\n";
19     }
20     return 0;
21 }
INPUT
5 2
2 3 4 5 1
1 7
3 1000000000000
OUTPUT

3
IDEA When every position has exactly one "next" position, 2ᵏ steps = two jumps of 2ᵏ⁻¹ steps. With the table, t
steps (even t = 10¹²) take one jump per 1-bit of t: O(log t) per query, the same binary idea as fast power.
KEY POINT Water falling through fountains (P7167), the fewest guards to cover a circle (P4155) and frogs jumping k
times (P3509) all build such a jump table and then jump by powers of two. In 第 9 章  the same table finds
lowest common ancestors in trees.

Key	points	to	memorise
1. Divide and conquer: split, solve halves, combine; O(n) combine → O(n log n).
2. Inversions: while merging, taking a[j] from the right adds m − i + 1; use long long.
3. Fast power: if (b & 1) res = res·a % p; a = a·a % p; b >>= 1.
4. Start from 1 % p; mod after every multiplication.
5. Crossing case: best ending at m (going left) + best starting at m + 1.
6. Closest pair: strip of width d around the middle, sorted by y, few checks per point.
7. ST table: mx[k][i] from two halves of length 2ᵏ⁻¹; query with k = log₂(len), two overlapping blocks.
8. Overlap is fine for max/min/gcd, not for sums.
9. Jump table: nxt[k][i] = nxt[k−1][nxt[k−1][i]]; jump by the 1-bits of t.
