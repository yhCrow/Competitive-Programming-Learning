20.1 加法原理和乘法原理
Add	separate	cases,	multiply	independent	steps,	subtract	the	complement.

IDEA Addition	principle ( 加法原理 ): if the ways split
into separate cases with no overlap, add the
counts of the cases. Multiplication	principle
( 乘法原理 ): if a choice is made in independent
steps, multiply the number of options at each
step.
KEY POINT Draw the choices as a tree: a branching step
multiplies, separate whole branches add. The
usual trap is double counting (cases that overlap)
or steps whose options depend on earlier
choices; then count the dependent step after
fixing the order.

distinct_numbers.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 int main() {
5     const long long MOD = 1000000007;
6     int n;
7     cin >> n;
8     vector<long long> mx(n);
9     for (int i = 0; i < n; i++) cin >> mx[i];
10     sort(mx.begin(), mx.end());              // most limited first
11     long long ways = 1;
12     for (int i = 0; i < n; i++) {
13         long long options = mx[i] - i;       // i numbers are already taken
14         if (options <= 0) { ways = 0; break; }
15         ways = ways * (options % MOD) % MOD;
16     }
17     cout << ways << "\n";
18     return 0;
19 }

IDEA Each rabbit picks a different number from 1 to its own maximum. Give numbers to the most limited rabbit
first: when it is rabbit i's turn (0-based), exactly i numbers inside its range are already used, so it has max
− i choices. Multiply (P1866).
KEY POINT Sorting makes each step's choices independent of which numbers were taken, only of how many. Take
every product % MOD  as you go.

rook_attack.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 int main() {
5     long long n;
6     int k;
7     cin >> n >> k;
8     vector<long long> rows(k), cols(k);
9     for (int i = 0; i < k; i++) cin >> rows[i] >> cols[i];
10     sort(rows.begin(), rows.end());
11     sort(cols.begin(), cols.end());
12     long long r = unique(rows.begin(), rows.end()) - rows.begin();
13     long long c = unique(cols.begin(), cols.end()) - cols.begin();
14     long long safe = (n - r) * (n - c);      // free row AND free column
15     cout << n * n - safe << "\n";            // complement
16     return 0;
17 }

IDEA Counting attacked cells directly double counts every cell that is hit by both a row and a column. Count the
complement instead: a cell is safe exactly when its row has no rook and its column has no rook, (n − r)(n
− c) cells by the multiplication principle (P3913).
KEY POINT "Count what you do not want, then subtract" avoids overlaps. Line intersections (P2789) split by how
many lines are parallel, and adding up the cases is the addition principle.

Pascal's rule C(n, k) = C(n−1,

C(5,2) = 4 + 6
symmetry C(n, k) = C(n, n − k) C(5,2) = C(5,3)
IDEA A permutation counts ordered
arrangements; a combination counts
unordered selections. Each combination
of k items can be ordered in k! ways, so
P(n, k) = C(n, k) · k!.
KEY POINT Pascal's rule: either item n is chosen (then
choose k − 1 of the rest) or it is not
(choose k of the rest). Filling the triangle
( 第 5 章 ) needs only additions, so no
division and no huge factorials.

comb_divisible.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 int C[2005][2005], S[2005][2005];   // C mod k, prefix counts of zeros
5  
6 int main() {
7     int t, k;
8     cin >> t >> k;
9     for (int i = 0; i <= 2000; i++) {
10         C[i][0] = 1 % k;
11         for (int j = 1; j <= i; j++) C[i][j] = (C[i - 1][j - 1] + C[i - 1][j]) % k;
12     }
13     for (int i = 0; i <= 2000; i++)
14         for (int j = 0; j <= 2000; j++) {
15             int hit = (j <= i && C[i][j] == 0) ? 1 : 0;
16             S[i][j] = hit + (i ? S[i - 1][j] : 0) + (j ? S[i][j - 1] : 0)
17                     - (i && j ? S[i - 1][j - 1] : 0);   // 2D prefix sum
18         }
19     while (t--) {
20         int n, m;
21         cin >> n >> m;
22         cout << S[n][m] << "\n";
23     }
24     return 0;
25 }

1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 long long C[30][30];
5  
6 int main() {
7     for (int i = 0; i <= 26; i++) {
8         C[i][0] = 1;
9         for (int j = 1; j <= i; j++) C[i][j] = C[i - 1][j - 1] + C[i - 1][j];
10     }
11     string s;
12     cin >> s;
13     int L = s.size();
14     for (int i = 1; i < L; i++)
15         if (s[i] <= s[i - 1]) { cout << 0 << "\n"; return 0; }  // not increasing
16     long long rank = 0;
17     for (int len = 1; len < L; len++) rank += C[26][len];      // shorter words
18     int prev = 0;                               // letters numbered 1..26
19     for (int i = 0; i < L; i++) {
20         int cur = s[i] - 'a' + 1;
21         for (int ch = prev + 1; ch < cur; ch++)  // a smaller letter here,
22             rank += C[26 - ch][L - i - 1];       // then any larger letters
23         prev = cur;
24     }
25     cout << rank + 1 << "\n";
26     return 0;
27 }

OUTPUT 1

INPUT 2
z
OUTPUT 2
26
INPUT 3

OUTPUT 3

INPUT 4

OUTPUT 4
0
IDEA Only words with strictly increasing letters get a code, ordered by length and then alphabetically. Code of a
word = 1 + (number of valid words before it): all shorter words, C(26, len) for each length, plus same-
length words that are smaller at the first differing position (P1246).
KEY POINT After fixing a smaller letter ch at position i, the remaining L − i − 1 letters are any increasing choice from
the 26 − ch letters above ch: C(26 − ch, L − i − 1). Stars-and-bars style splitting (P2638) is another "choose
positions" count.

Key	points	to	memorise
1. Separate cases: add. Independent steps: multiply.
2. Overlaps are hard to count: count the complement and subtract.
3. Steps that depend on earlier choices: order them (sort) so only how many, not which, matters.
4. n! arrangements; P(n, k) = n!/(n−k)!; C(n, k) = n!/(k!(n−k)!).
5. P(n, k) = C(n, k) · k!.
6. Pascal: C(n,	k)	=	C(n−1,	k−1)	+	C(n−1,	k); works mod any k.
7. Many range queries: 2D prefix sums over the triangle.
8. Rank of an object = 1 + count of smaller objects, position by position.
