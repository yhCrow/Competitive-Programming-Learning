IDEA Two	pointers ( 双指针 ): keep a window
[l, r] and move both ends only forward.
Each pointer travels at most n steps, so
the whole scan is O(n), even though it
looks at "all windows". It works when
moving r forward can only make the
window "more" (bigger sum, more
kinds) and moving l forward can only
make it "less".
KEY POINT Same-direction pointers handle
"shortest / longest window with a
property". Opposite-direction pointers
(one at each end of a sorted array,
moving inward) handle "pairs with a
given sum or difference".

all_painters.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 int a[1000005], cnt[2005];
5  
6 int main() {
7     ios::sync_with_stdio(false);
8     cin.tie(nullptr);
9     int n, m;
10     cin >> n >> m;
11     for (int i = 1; i <= n; i++) cin >> a[i];
12     int kinds = 0, bestL = 1, bestR = n, l = 1;
13     for (int r = 1; r <= n; r++) {
14         if (cnt[a[r]]++ == 0) kinds++;             // a new painter enters
15         while (kinds == m) {                        // window has everyone:
16             if (r - l < bestR - bestL) { bestL = l; bestR = r; }
17             if (--cnt[a[l]] == 0) kinds--;          // try to shrink from the left
18             l++;
19         }
20     }
21     cout << bestL << " " << bestR << "\n";
22     return 0;
23 }

2 5 3 1 3 2 4 1 1 5 4 3
OUTPUT
2 7
KEY POINT For each right end r, the shortest good window ends at r and starts at the largest l that still keeps every
painter. That l never moves back when r grows, so l and r together move at most 2n times (P1638). Keep a
cnt[]  array and a kinds  counter so each step is O(1).

pairs_two_pointers.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 int main() {
5     int n;
6     long long c;
7     cin >> n >> c;
8     vector<long long> a(n);
9     for (int i = 0; i < n; i++) cin >> a[i];
10     sort(a.begin(), a.end());
11     long long cnt = 0;
12     int lo = 0, hi = 0;                   // a[lo..hi) all equal x + c
13     for (int i = 0; i < n; i++) {
14         while (lo < n && a[lo] < a[i] + c) lo++;
15         while (hi < n && a[hi] <= a[i] + c) hi++;
16         cnt += hi - lo;                   // b = a[i], a = b + c
17     }
18     cout << cnt << "\n";
19     return 0;
20 }

KEY POINT Longest window without repeats (UVA11572) shrinks only when the new value is already inside.
Counting pairs with a − b = c (P1102) after sorting: as a[i] grows, the block of values equal to a[i] + c only
moves right, so two pointers replace the binary searches of 第 13 章 . Diamond Collector (P3143) and Sure
Bet (P4653) are two-pointer scans on sorted data.

1.2 空间换时间
Store	running	values	and	counts	so	each	step	is	O(1).
IDEA Space	for	time ( 空间换时间 ): store results you would otherwise recompute, such as a running total, a
prefix minimum or a count per value, so each step reads them in O(1). The cost is memory, which is
usually plentiful compared with time.
max_subarray.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 int main() {
5     int n;
6     cin >> n;
7     long long best = LLONG_MIN, here = 0;   // best sum ending at i
8     for (int i = 0; i < n; i++) {
9         long long x;
10         cin >> x;
11         here = max(here + x, x);            // extend, or start again at x
12         best = max(best, here);
13     }
14     cout << best << "\n";
15     return 0;
16 }

IDEA Checking all O(n²) subarrays is too slow for n = 2 × 10⁵. Keep only one stored value: the best sum of a
subarray ending at the current position. It either extends the previous best or starts fresh, whichever is
larger (P1115).
KEY POINT The same answer comes from prefix sums: best = max over r of (S[r] − min S[l] for l < r), with the
minimum stored as you go. One stored number replaces a whole inner loop.

10     cin >> n >> w;
11     for (int i = 1; i <= n; i++) {
12         int s;
13         cin >> s;
14         cnt[s]++;
15         int need = max(1, i * w / 100);     // winners after i players
16         int seen = 0, line = 600;
17         while (true) {                      // walk down the scores
18             seen += cnt[line];
19             if (seen >= need) break;
20             line--;
21         }
22         cout << line << " ";
23     }
24     cout << "\n";
25     return 0;

10 60
200 300 400 500 600 600 0 300 200 100

IDEA Re-sorting after every new score costs O(n log n) each time. Scores are only 0 … 600, so store a count	per
score and walk down from 600 until enough winners are covered: at most 601 steps per player (P7072).
KEY POINT When values come from a small range, a counting array ( 基础篇  第 5 章 ) is the "space" that buys the time.
Grouping indices by colour and parity before pairing them up (P2671) is the same idea with sums stored
per group.
1.3 单调栈
Nearest	greater	/	smaller	elements;	largest	rectangles.
10 3 7 4 9 2
stack keeps
decreasing
heights
IDEA A monotonic	stack ( 单调栈 ) keeps its
contents sorted, for example decreasing from
bottom to top. Before pushing x, pop
everything that x "beats". Each element is
pushed once and popped at most once: O(n)
in total.
KEY POINT At the moment an element is popped, the
element causing the pop is its next	greater
(or smaller) element to the right. What
remains below it in the stack is its nearest
greater element to the left.

largest_rectangle.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 int h[1005], lft[1005], rgt[1005];
5  
6 int main() {
7     int n, m;
8     cin >> n >> m;
9     long long best = 0;
10     for (int i = 0; i < n; i++) {
11         for (int j = 1; j <= m; j++) {
12             char ch;
13             cin >> ch;
14             h[j] = (ch == 'F') ? h[j] + 1 : 0;      // column height of F's
15         }
16         h[0] = h[m + 1] = -1;                        // walls
17         stack<int> st;
18         for (int j = 1; j <= m + 1; j++) {           // nearest lower to the right
19             while (!st.empty() && h[st.top()] > h[j]) { rgt[st.top()] = j; st.pop(); }
20             st.push(j);
21         }
22         while (!st.empty()) st.pop();
23         for (int j = m; j >= 0; j--) {               // nearest lower to the left
24             while (!st.empty() && h[st.top()] > h[j]) { lft[st.top()] = j; st.pop(); }
25             st.push(j);
26         }
27         for (int j = 1; j <= m; j++)
28             best = max(best, 1LL * h[j] * (rgt[j] - lft[j] - 1));
29     }
30     cout << 3 * best << "\n";                        // each cell is worth 3
31     return 0;
32 }

5 6

F F F F F F
R R R F F F

KEY POINT Largest rectangle of F cells: for every row, h[j] is how many F cells stand in column j ending at this row.
The best rectangle with height h[j] stretches left and right until the first lower column, found for all j with
two monotonic-stack passes: O(nm) overall (P4147). Counting all rectangles (P1950) and the poster
problem (P3467) use the same "nearest lower" arrays.

IDEA A monotonic	queue ( 单调队列 ) finds
the minimum (or maximum) of every
window of length k in O(n) total. Keep a
deque  of indices whose values increase
from front to back: a new value pops
every bigger value from the back, because
those can never be a window minimum
again; the front leaves when it falls out of
the window.
KEY POINT The front of the deque is always the
minimum of the current window. Each
index enters and leaves once.
sliding_window.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 int a[1000005];
5  
6 int main() {
7     ios::sync_with_stdio(false);
8     cin.tie(nullptr);
9     int n, k;
10     cin >> n >> k;
11     for (int i = 0; i < n; i++) cin >> a[i];
12     deque<int> q;                                   // indices, values increasing
13     for (int i = 0; i < n; i++) {
14         while (!q.empty() && a[q.back()] >= a[i]) q.pop_back();   // can never win
15         q.push_back(i);
16         if (q.front() <= i - k) q.pop_front();      // fell out of the window
17         if (i >= k - 1) cout << a[q.front()] << " ";
18     }
19     cout << "\n";
20     q.clear();                                      // same with values decreasing
21     for (int i = 0; i < n; i++) {
22         while (!q.empty() && a[q.back()] <= a[i]) q.pop_back();
23         q.push_back(i);
24         if (q.front() <= i - k) q.pop_front();
25         if (i >= k - 1) cout << a[q.front()] << " ";
26     }
27     cout << "\n";
28     return 0;
29 }

cut_cake.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 long long S[500005];
5  
6 int main() {
7     int n, m;
8     cin >> n >> m;
9     for (int i = 1; i <= n; i++) { long long x; cin >> x; S[i] = S[i - 1] + x; }
10     deque<int> q;                         // candidate left ends, S increasing
11     q.push_back(0);
12     long long best = LLONG_MIN;
13     for (int r = 1; r <= n; r++) {
14         if (q.front() < r - m) q.pop_front();          // length would exceed m
15         best = max(best, S[r] - S[q.front()]);          // smallest S on the left
16         while (!q.empty() && S[q.back()] >= S[r]) q.pop_back();
17         q.push_back(r);
18     }
19     cout << best << "\n";
20     return 0;
21 }

INPUT 2

IDEA Best sum of at most m consecutive pieces: with prefix sums, the sum of (l, r] is S[r] − S[l], so for each r we
want the smallest S[l] with r − m ≤ l < r: a sliding-window minimum over the prefix sums (P1714).
KEY POINT Window maximum (P2032), the max − min of every k × k square by running the queue on rows and then
on columns (P2216), and recurrences like "best of the last k states" (P1725) all reuse this deque. Range
max/min with arbitrary queries (P2880) needs a sparse table ( 第 3 章 ).
1.5 课后习题与实验
The	Luogu	problems	for	this	chapter,	a	ladder	through	them,	and	experiments	to	try	yourself.
Key	points	to	memorise
1. Two pointers: both ends only move forward → O(n) for all windows.
2. Shortest window with a property: grow r, then shrink l while still good.
3. Keep counts and a "kinds" counter so each pointer step is O(1).
4. Space for time: store running bests, prefix minima, counts per value.
5. Max subarray: here = max(here + x, x); best = max(best, here).
6. Monotonic stack: pop what the new element beats; popped → its next greater/smaller.
7. Largest rectangle: nearest lower on both sides × height.
8. Monotonic queue: deque of indices; pop worse from the back, expired from the front.
9. Window sum ≤ m long: S[r] − min S[l] over the window, by a monotonic queue.
