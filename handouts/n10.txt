10.1 三维凸包
Visible	faces,	horizon	edges,	perturbation.
IDEA The 3D	convex	hull ( 三维凸包 ) is made of triangular faces. Incremental	construction: start with a
tetrahedron, then add points one by one. A face is visible from the new point p if p lies on its outer side
(positive triple product). Delete all visible faces; the edges on the border between visible and invisible
faces (the "horizon") each form a new face with p. O(n²) total, enough for n ≤ 2000 (P4724).
KEY POINT Mark visibility per directed edge: for each face (a, b, c) visible from p, set vis[a][b] = vis[b][c] = vis[c][a].
An edge (a, b) of a kept face with vis[b][a] set is a horizon edge, and the new face is (a, b, p) with the same
orientation. Perturb the points by about 10⁻⁹ first, so that no four points are coplanar.
竞 赛 拓 展 专 题  · NOI 篇  · NOI 专 题
Grow a 3D hull by deleting the faces a new point sees, find the smallest enclosing sphere, add convex
polygons with Minkowski sums, and integrate areas numerically with adaptive Simpson.

10.2 最小球覆盖
Four	nested	loops;	circumsphere	by	elimination.
IDEA The minimum	enclosing	sphere ( 最小球覆盖 ) extends the random incremental circle of 拓展篇  第 15 章
one level deeper: shuffle the points; whenever point i is outside the current sphere, restart with i on the
boundary; inside that, whenever j is outside, restart with i and j on the boundary; then k; then l, where four
boundary points fix the sphere. Expected O(n) after shuffling.
KEY POINT The sphere through 2 points: centre at the midpoint. Through 3: the circumcircle centre in their plane.
Through 4: solve the 3 × 3 linear system |c − pi|² = |c − p0|² (Gaussian elimination, 进阶篇  第 22 章 ).

12 V circum3(V a, V b, V c) {                      // centre of the circle through a, b, c (in their plane)
13     V ab = b - a, ac = c - a, n = cross(ab, ac);
14     V t = cross(n, ab) * dot(ac, ac) + cross(ac, n) * dot(ab, ab);
15     return a + t * (1.0 / (2 * dot(n, n)));
16 }
17 V circum4(V a, V b, V c, V d) {                 // solve 2 (p_i - a) . x = |p_i|^2 - |a|^2
18     double M[3][4];
19     V ps[3] = {b, c, d};
20     for (int i = 0; i < 3; i++) {
21         V q = ps[i] - a;
22         M[i][0] = 2 * q.x; M[i][1] = 2 * q.y; M[i][2] = 2 * q.z;
23         M[i][3] = dot(ps[i], ps[i]) - dot(a, a);
24     }
25     for (int col = 0; col < 3; col++) {          // Gaussian elimination
26         int piv = col;
27         for (int r = col; r < 3; r++) if (fabs(M[r][col]) > fabs(M[piv][col])) piv = r;
28         for (int j = 0; j < 4; j++) swap(M[col][j], M[piv][j]);
29         for (int r = 0; r < 3; r++) if (r != col) {
30             double f = M[r][col] / M[col][col];
31             for (int j = col; j < 4; j++) M[r][j] -= f * M[col][j];
32         }
33     }
34     return V{M[0][3] / M[0][0], M[1][3] / M[1][1], M[2][3] / M[2][2]};
35 }

10.3 闵可夫斯基和
Merge	edge	lists	by	angle.
IDEA The Minkowski	sum ( 闵可夫斯基和 ) A + B = {a + b} of two convex polygons is convex, and its edges are
the edges of A and B sorted	by	angle. Start both at their lowest (then leftmost) vertex and merge the two
edge lists like merge sort, comparing directions by cross product: O(n + m).
KEY POINT Typical uses: "can polygon B moved by vector v touch A?" ⇔ v ∈ A + (−B) (P4557 战争 ), distances
between convex polygons, and motion planning. Remove collinear vertices afterwards if the problem
wants a strict polygon.

10 vector<P> readPoly() {
11     int n; cin >> n;
12     vector<P> a(n);
13     for (int i = 0; i < n; i++) cin >> a[i].x >> a[i].y;   // counter-clockwise
14     int k = 0;

16     rotate(a.begin(), a.begin() + k, a.end());              // start at the lowest point
17     a.push_back(a[0]); a.push_back(a[1]);
18     return a;

21 int main() {
22     vector<P> A = readPoly(), B = readPoly();
23     int n = A.size() - 2, m = B.size() - 2, i = 0, j = 0;
24     vector<P> r;

26         r.push_back(A[i] + B[j]);

10.4 自适应辛普森与 	Voronoi
Split	until	halves	agree;	union	of	circles.
IDEA Adaptive	Simpson	integration ( 自适应辛普森 ): Simpson's rule ∫lr f ≈ (r − l)(f(l) + 4f(m) + f(r)) / 6.
Compare the whole interval with its two halves; if they agree within 15·ε accept, otherwise recurse on
each half with ε / 2. The function only needs to be evaluable, not integrable by hand.
KEY POINT Classic use: the area	of	a	union	of	circles (or other shapes) as ∫ f(x) dx, where f(x) = total length of the
union of the vertical chords at x (merge intervals). Integrate each connected x-range separately (f = 0 in
gaps fools the error test), and force a few levels of recursion before trusting the error estimate.

7 double f(double x) {                               // length of the union of chords at x
8     vector<pair<double, double>> iv;
9     for (int i = 0; i < n; i++) {
10         double dx = fabs(x - cx[i]);
11         if (dx >= cr[i]) continue;
12         double h = sqrt(cr[i] * cr[i] - dx * dx);
13         iv.push_back({cy[i] - h, cy[i] + h});
14     }
15     sort(iv.begin(), iv.end());
16     double len = 0, lo = -1e18, hi = -1e18;
17     for (int i = 0; i < int(iv.size()); i++) {
18         if (iv[i].first > hi) { len += hi - lo; lo = iv[i].first; hi = iv[i].second; }
19         else hi = max(hi, iv[i].second);
20     }
21     return len + hi - lo;
22 }
23 double simpson(double l, double r, double fl, double fm, double fr) { return (r - l) * (fl + 4 * fm + 
fr) / 6; }
24 double asr(double l, double r, double fl, double fm, double fr, double whole, double eps, int depth) {
25     double m = (l + r) / 2, lm = (l + m) / 2, rm = (m + r) / 2, flm = f(lm), frm = f(rm);
26     double L = simpson(l, m, fl, flm, fm), R = simpson(m, r, fm, frm, fr);
27     if (depth <= 0 && fabs(L + R - whole) <= 15 * eps) return L + R + (L + R - whole) / 15;
28     return asr(l, m, fl, flm, fm, L, eps / 2, depth - 1) + asr(m, r, fm, frm, fr, R, eps / 2, depth - 
1);
29 }

TRAP Simpson assumes f is smooth; at chord ends f has √ cusps, which is why the adaptive version (not a fixed
number of slices) is needed. ε too small makes it slow: pick it a few digits below the required precision.
KEY POINT Voronoi	diagram	and	Delaunay	triangulation (Voronoi 图  / Delaunay 三角剖分 ): the Voronoi cell of a
site is the set of points nearest to it; joining sites whose cells share an edge gives the Delaunay
triangulation (no point inside any triangle's circumcircle). Both have O(n) size and are built in O(n log n)
(divide and conquer or Fortune's sweep). The Euclidean MST is a subgraph of the Delaunay triangulation.
They are rare in NOI; know them by name and use half-plane intersection ( 拓展篇 ) for small n.
10.5 课后习题与实验
The	Luogu	problems	for	this	chapter,	a	ladder	through	them,	and	experiments	to	try	yourself.
Key	points	to	memorise
1. Face visible from p: positive triple product.
2. Delete visible faces; horizon edge (visible one side only) + p ⇒ new face.
3. Perturb by ~1e-9 against coplanar points; O(n²).
4. Min sphere: shuffle; nested loops with 1, 2, 3, 4 boundary points; expected O(n).
5. Minkowski: start at lowest points, merge edges by cross product; O(n + m).
6. Adaptive Simpson: |L + R − S| ≤ 15ε ⇒ accept; integrate each x-component separately.
