10.1 Nim	 游戏
Winning	/	losing	positions;	XOR	of	piles.
IDEA In an impartial	game ( 公平组合游戏 ) both players have the same moves, they alternate, and whoever
cannot move loses. Every position is either winning (some move leads to a losing position) or losing
(every move leads to a winning position, or there is no move). Positions with no moves are losing.
KEY POINT Nim: several piles, a move removes any positive number of stones from one pile. The first player wins
exactly when the XOR of all pile sizes is non-zero. From a non-zero XOR there is always a move to XOR 0,
and from XOR 0 every move makes it non-zero.
nim.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 int main() {
5     int T;
6     cin >> T;
7     while (T--) {
8         int n, x = 0;
9         cin >> n;
10         for (int i = 0; i < n; i++) { int a; cin >> a; x ^= a; }
11         cout << (x != 0 ? "Yes" : "No") << "\n";   // first player wins?
12     }
13     return 0;
14 }

10.2 SG	 函数
mex	of	moves;	a	sum	of	games	XORs	its	SG	values.
IDEA The Sprague–Grundy	theorem: every impartial position has a Grundy	number SG = mex of the SG
values of the positions it can move to (mex = smallest non-negative integer not in the set). A position is
losing iff SG = 0, and a sum	of	independent	games has SG = XOR of their SG values: every game behaves
like a Nim pile of size SG.
KEY POINT So: compute SG for one small game by brute force (memoised mex), then XOR across the independent
parts. A Nim pile of size n has SG = n, which is why plain Nim uses the XOR of the sizes.
subtraction_game.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 int sg[100005];
5  
6 int main() {
7     int k;
8     cin >> k;
9     vector<int> s(k);
10     for (int i = 0; i < k; i++) cin >> s[i];          // allowed numbers to remove
11     int n;
12     cin >> n;
13     vector<int> pile(n);
14     int mx = 0;
15     for (int i = 0; i < n; i++) { cin >> pile[i]; mx = max(mx, pile[i]); }
16     for (int x = 0; x <= mx; x++) {                   // sg[x] = mex of reachable values
17         vector<bool> seen(k + 2, false);              // mex is at most k
18         for (int i = 0; i < k; i++)
19             if (s[i] <= x && sg[x - s[i]] <= k) seen[sg[x - s[i]]] = true;
20         int m = 0;
21         while (seen[m]) m++;
22         sg[x] = m;
23     }
24     int x = 0;
25     for (int i = 0; i < n; i++) x ^= sg[pile[i]];     // sum of games = XOR
26     cout << (x ? "first" : "second") << "\n";
27     return 0;
28 }

IDEA Subtraction game: from a pile you may remove 1, 3 or 4 stones. SG values for 0, 1, 2, … are 0, 1, 0, 1, 2, 3, 2,
0, 1, 0, 1, 2, … (periodic). Several piles: XOR their SG values. The expected answers here come from an
independent Python computation.
KEY POINT A position's SG has at most k + 1 possible values when there are k moves, so the "seen" array only needs
size k + 2. Splitting moves (one pile becomes two) give SG = XOR of the parts, inside the mex ( 分裂游戏
P3185, E&D P2148).
10.3 经典博弈
Wythoff,	anti-Nim,	Euclid's	game.
IDEA Some games have a formula instead. Wythoff's	game ( 威佐夫博弈 ): two piles; remove any amount from
one pile, or the same amount from both. With a ≤ b, the position is losing exactly when a = ⌊(b − a) · φ⌋, φ
= (1 + √5)/2 (P2252).
KEY POINT Anti-Nim ( 反  Nim, the player taking the last stone loses, P4279): the first player wins iff (all piles are 1
and their number is even) or (some pile is > 1 and the XOR is non-zero). Euclid's	game (P1290): whoever
first meets a pair with b ≥ 2a can always win.
wythoff.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 int main() {
5     long long a, b;
6     cin >> a >> b;
7     if (a > b) swap(a, b);
8     long double phi = (1 + sqrtl(5.0L)) / 2;
9     long long cold = llround(floorl((b - a) * phi));  // the losing position with this difference
10     cout << (a == cold ? 0 : 1) << "\n";              // 1: the first player wins
11     return 0;
12 }

IDEA Losing positions (a, b): (0, 0), (1, 2), (3, 5), (4, 7), (6, 10), … Each difference b − a = 0, 1, 2, 3, … appears
exactly once, and a is ⌊difference · φ⌋.
KEY POINT Use long double (or exact integer checks) for φ: with values up to 10⁹ a double can round the wrong way.
When no formula is known, compute SG values for small sizes and look	for	a	pattern, then prove or trust
it.

10.4 课后习题与实验
The	Luogu	problems	for	this	chapter,	a	ladder	through	them,	and	experiments	to	try	yourself.
Key	points	to	memorise
1. No move ⇒ losing; winning ⇔ some move to a losing position.
2. Nim: first player wins ⇔ XOR ≠ 0; move a pile a to a ⊕ x.
3. SG(x) = mex of SG of moves; losing ⇔ SG = 0.
4. Independent games: XOR the SG values.
5. Wythoff (a ≤ b): losing ⇔ a = ⌊(b − a)φ⌋.
6. Anti-Nim: win ⇔ (all 1 and even count) or (some > 1 and XOR ≠ 0).
7. No formula? Tabulate SG for small sizes and look for a pattern.
