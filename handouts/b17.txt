17.1 并查集
find	and	union	with	path	compression.

each set is a tree; the root (green) names the set
IDEA Union-find ( 并查集 , disjoint set union) keeps
items split into groups and answers two
questions fast: find "which group is x in?" and
union "merge the groups of x and y". Each group
is a tree stored in a parent[]  array; the root
represents the group.
KEY POINT Path	compression: while finding the root, point
every node on the way straight at the root. After
that, operations are almost O(1) each.
深 入 浅 出 程 序 设 计 竞 赛  · 基 础 篇  · 第 3 部 分  简 单 数 据 结 构
Union-find for merging groups, hashing for fast lookup, and set/map for sorted collections.

KEY POINT Relatives are a union-find on people (P1551). To connect g separate groups you need exactly g − 1 more
roads, and every successful union lowers g by one (P1536). Family trees with names use map<string,
string>  as the parent array (P2814).
KEY POINT "The enemy of my enemy is my friend": give each person i a second node i + n meaning "i's enemies", and
unite a with b + n, b with a + n (P1892). Checking constraints in the right order, equalities first, uses the
same tool after compressing big numbers (P1955).
17.2 Hash	 表
String	hashing	and	the	unordered	containers.
IDEA A hash turns a key (a number, a string) into a small index, so the key can be stored in or looked up from
an array slot directly. Different keys may land on the same index (a collision); a good hash makes that
rare, and a hash table keeps a short list per slot.

string_hash.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 unsigned long long hashOf(const string &s) {
5     unsigned long long h = 0;
6     for (int i = 0; i < int(s.size()); i++)
7         h = h * 131 + s[i];          // overflow wraps mod 2^64
8     return h;
9 }
10  
11 int main() {
12     int n;
13     cin >> n;
14     vector<unsigned long long> h(n);
15     for (int i = 0; i < n; i++) {
16         string s;
17         cin >> s;
18         h[i] = hashOf(s);
19     }
20     sort(h.begin(), h.end());
21     int distinct = unique(h.begin(), h.end()) - h.begin();
22     cout << distinct << "\n";
23     return 0;
24 }
INPUT
5
abc
aaaa
abc
abcc
12345
OUTPUT
4
KEY POINT Read the string as a number in base 131 and let unsigned long long  overflow, which is arithmetic mod
264. Equal strings always get equal hashes; different strings almost never do. Then count distinct values
with sort + unique (P3370).
TRAP A hash compares fingerprints, not the strings themselves: a collision gives a wrong answer silently. Use a
large base and mod 264 (or two different hashes) to make it practically impossible.

17.3 集合应用实例
set	and	map	in	practice:	nearest	values	and	records.
IDEA set  keeps distinct values sorted; map  keeps (key, value) pairs sorted by key. Besides insert, find and
erase in O(log n), they answer "nearest value" questions with lower_bound , which a hash table cannot do.

timber_store.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 int main() {
5     int n;
6     cin >> n;
7     set<int> wood;
8     while (n--) {
9         int op, len;
10         cin >> op >> len;
11         if (op == 1) {
12             if (wood.count(len)) cout << "Already Exist\n";
13             else wood.insert(len);
14             continue;
15         }
16         if (wood.empty()) { cout << "Empty\n"; continue; }
17         set<int>::iterator it = wood.lower_bound(len);   // first >= len
18         int pick;
19         if (it == wood.end()) pick = *prev(it);          // all are smaller
20         else if (it == wood.begin()) pick = *it;         // all are larger
21         else {
22             int big = *it, small = *prev(it);
23             pick = (len - small <= big - len) ? small : big;   // tie: smaller
24         }
25         cout << pick << "\n";
26         wood.erase(pick);
27     }
28     return 0;
29 }

Key	points	to	memorise
1. Union-find: parent[x]	=	x at start; find the root; union = point one root at the other.
2. Path compression: parent[x]	=	find(parent[x]).
3. g groups need g − 1 links; each successful union lowers g by 1.
4. Enemies: extra node i + n means "i's enemies".
5. String hash: h = h × 131 + c in unsigned long long (mod 2⁶⁴).
6. Hash containers: O(1) average, unordered; set/map: O(log n), sorted.
7. Nearest value in a set: lower_bound and the element before it.
8. map[key] creates a missing key; use count() to test, erase() returns how many removed.
