3.1.1 Conditions
Operator Meaning Example
== != equal, not equal x % 2 == 0  (even)
< <= > >= compare a <= b
&& and: both true 1 <= x && x <= 9
|| or: at least one c == 'a' || c == 'A'
! not !(x > 5)
a % b == 0 b divides a n % 3 == 0
Precedence, high to low: !  → arithmetic → < >  → == !=
→ &&  → || . Add brackets whenever you mix &&  and || .
KEY POINT Short-circuit: &&  stops at the first false
part, ||  at the first true part. So n != 0
&& a / n > 2  never divides by zero.
TRAP if (a = b)  assigns instead of comparing. 1 < x < 5  means (1 < x) < 5 , which is always true. if
(x);  has an empty body. An else  pairs with the nearest if : use braces.

3.2.1 if	/	else	if	/	else,	and	switch
IDEA An else-if	chain tests conditions in order and runs only the first that is true. Order matters: put the narrow
cases first, or write each condition so it cannot overlap.
month_days.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 int main() {
5     int y, m;
6     cin >> y >> m;
7     bool leap = (y % 4 == 0 && y % 100 != 0) || y % 400 == 0;
8     int days;
9     switch (m) {
10         case 2: days = leap ? 29 : 28; break;
11         case 4: case 6: case 9: case 11: days = 30; break;
12         default: days = 31;
13     }
14     cout << days << "\n";
15     return 0;
16 }

3.3 分支嵌套
Decisions	inside	decisions.
x == 0 || y == 0 ?
on an axis x > 0 ?
y > 0 ? 1 : 4 y > 0 ? 2 : 3
yes no
IDEA An if  inside another if  makes a decision
tree: the inner question is only asked on one
branch of the outer one. Draw the tree first
when the cases depend on each other.
KEY POINT Braces show which else  belongs to which
if . Many nests can be flattened into an else
if  chain with && , which is often easier to
read.

3.4.1 Sorting	three	values	and	the	triangle	test
triangle.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 int main() {
5     long long a, b, c;
6     cin >> a >> b >> c;
7     if (a > b) swap(a, b);       // three swaps sort a <= b <= c
8     if (b > c) swap(b, c);
9     if (a > b) swap(a, b);
10     if (a + b <= c) { cout << "Not triangle\n"; return 0; }
11     if (a * a + b * b == c * c) cout << "Right\n";
12     else if (a * a + b * b > c * c) cout << "Acute\n";
13     else cout << "Obtuse\n";
14     if (a == c) cout << "Equilateral\n";
15     else if (a == b || b == c) cout << "Isosceles\n";
16     return 0;
17 }
INPUT 1
5 3 4
OUTPUT 1
Right
INPUT 2
2 2 3
OUTPUT 2
Obtuse
Isosceles
INPUT 3
1 2 3
OUTPUT 3
Not triangle
After sorting, one test decides each question:
Is	it	a	triangle? a + b > c.
Angle	type: compare a² + b² with c². Equal: right. Greater: acute. Smaller: obtuse.
Equilateral: a == c (sorted, so all three equal).
Isosceles: a == b or b == c.
KEY POINT All tests stay in integers, so there is no rounding error. Sorting first removes the "which side is longest"
case analysis.

3.4.2 Choosing	the	cheapest	option
pencils.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3 #define int long long
4  
5 signed main() {
6     int n;
7     cin >> n;
8     int best = LLONG_MAX;
9     for (int k = 0; k < 3; k++) {          // 3 kinds of pack
10         int size, price;
11         cin >> size >> price;
12         int packs = (n + size - 1) / size; // round up
13         best = min(best, packs * price);
14     }
15     cout << best << "\n";
16     return 0;
17 }
INPUT
57
2 2
50 30
30 27
OUTPUT
54
IDEA Compute the cost of each choice and keep the minimum. Start the minimum at a value larger than any
answer (LLONG_MAX ), or at the first choice. The idea behind P1909.
TRAP 0.1 + 0.2 == 0.3  is false for doubles. Compare with a tolerance, fabs(x - y) < 1e-9 , or better,
multiply out so everything stays an integer.
3.5 课后习题与实验
The	Luogu	problems	for	this	chapter,	a	ladder	through	them,	and	experiments	to	try	yourself.
Key	points	to	memorise
1. Comparisons give bool: true (1) or false (0); any non-zero counts as true.
2. && and || short-circuit: n != 0 && a / n > 2 is safe.
3. 1	<	x	<	5 is wrong; write 1 < x && x < 5.
4. else-if chains test in order and run only the first true branch.
5. switch: each case needs break; ?	: picks one of two values.
6. Nested ifs: braces always; else binds to the nearest if.
7. Leap year: (y%4==0	&&	y%100!=0)	||	y%400==0.
8. Sort three with swaps; triangle if a + b > c; compare a²+b² with c² exactly.
