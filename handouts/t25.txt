25.1 洪水填充
Connected	regions;	mark	on	push.
IDEA Flood	fill ( 洪水填充 ): starting from a cell, visit every connected cell of the same kind (BFS or DFS) and
mark it. Counting how many times a new fill has to start counts the connected	regions. "Connected"
must be defined: 4 neighbours (edges) or 8 neighbours (edges and corners).
KEY POINT Mark cells when they are pushed, not when they are popped, or a cell can enter the queue many times. On
large grids prefer BFS or an explicit stack over recursion, which can overflow on a 1000 × 1000 region.
竞 赛 拓 展 专 题  · 拓 展 篇  · 基 础 补 充

25.2 双向广搜
Two	frontiers;	expand	the	smaller	layer.
IDEA Bidirectional	BFS ( 双向广搜 ): when the start and the goal are both known, search from both ends at once
and stop when the two frontiers meet. If each state has b neighbours and the answer is d, one BFS visits
about bd states, two half-searches about 2·bd/2: the square root.
KEY POINT Expand the smaller frontier each round, one whole layer at a time; when a newly reached state is already
known from the other side, answer = its distance from this side + its distance from the other side. The
moves must be reversible (or searched backwards with reversed moves).

17         int layer = q[s].size();

19             string u = q[s].front(); q[s].pop();
20             int z = u.find('0');

22                 int x = z / 3 + dx[k], y = z % 3 + dy[k];
23                 if (x < 0 || x > 2 || y < 0 || y > 2) continue;
24                 string v = u;
25                 swap(v[z], v[x * 3 + y]);

25.3 IDA*
Deepening	on	g	+	h;	search	summary.
IDEA IDA* = iterative deepening ( 进阶篇  第 4 章 ) + an A* estimate h. Search depth-first with a bound D on g + h:
cut any branch where moves so far + the estimate of moves still needed > D. If the search fails, raise D.
Memory is just the recursion stack, and a good h cuts most of the tree.
KEY POINT h must never overestimate (as in A*). For sliding or swapping puzzles, "number of misplaced pieces" (or
that number divided by what one move can fix) is the usual choice. Also skip the move that undoes the
previous one.

5 char b[5][6];

7 int limit;

9 int h() {                                        // misplaced knights: each move fixes at most one
10     int c = 0;
11     for (int i = 0; i < 5; i++) for (int j = 0; j < 5; j++) if (b[i][j] != goal[i][j] && b[i][j] != '*') 
c++;
12     return c;
13 }
14 bool dfs(int g, int x, int y, int lastK) {
15     int est = h();
16     if (est == 0) return true;
17     if (g + est > limit) return false;           // the IDA* cut
18     for (int k = 0; k < 8; k++) {
19         if (lastK >= 0 && k == (lastK ^ 1)) continue;   // do not undo the previous move
20         int a = x + dx[k], c = y + dy[k];
21         if (a < 0 || a > 4 || c < 0 || c > 4) continue;
22         swap(b[x][y], b[a][c]);                  // move a knight into the empty square
23         if (dfs(g + 1, a, c, k)) return true;
24         swap(b[x][y], b[a][c]);
25     }
26     return false;
27 }

Search Order Memory Best for
BFS by distance whole layer shortest path, unit steps
DFS + pruning deep first path only existence, counting, small answers
BFS + deque (0-1 BFS) by distance layer weights 0/1 ( 第 17 章 )
BFS + priority queue by cost all reached Dijkstra, weighted steps
A* by g + h all reached one target, good estimate
IDA* deepening on g + h path only one target, little memory
bidirectional BFS both ends 2 half-searches known start and goal, reversible moves
25.4 课后习题与实验
The	Luogu	problems	for	this	chapter,	a	ladder	through	them,	and	experiments	to	try	yourself.
Key	points	to	memorise
1. Flood fill: BFS/DFS per new region; mark on push.
2. Bidirectional BFS: b^(d/2) per side; expand smaller frontier by whole layers.
3. Meeting state: answer = dist from side A + dist from side B.
4. IDA*: DFS with bound on g + h; increase the bound until success.
5. h must not overestimate; forbid undoing the last move.
