31.1 鸽巢原理
n	+	1	into	n;	prefix	remainders.
IDEA The pigeonhole	principle ( 鸽巢原理 ): putting n + 1 objects into n boxes forces some box to hold two.
Stronger form: kn + 1 objects force some box to hold k + 1. It proves that something must	exist, and the
proof usually tells you where to look.
KEY POINT Classic use: among any n integers there is a non-empty block al + … + ar divisible by n. The n + 1 prefix
sums S0 … Sn have only n possible remainders mod n, so two are equal; their difference is the block. The
proof is the O(n) algorithm.
pigeonhole.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 int main() {
5     int n;
6     cin >> n;
7     vector<int> first(n, -1);                 // first prefix index with each remainder
8     first[0] = 0;
9     long long s = 0;
10     for (int i = 1; i <= n; i++) {
11         long long x; cin >> x;
12         s = (s + x) % n;
13         if (first[s] >= 0) { cout << first[s] + 1 << " " << i << "\n"; return 0; }   // equal remainders
14         first[s] = i;
15     }
16     return 0;                                 // never reached: n+1 prefixes, n remainders
17 }

31.2 母函数
OGF	for	combinations,	EGF	for	arrangements.
IDEA A generating	function ( 母函数 ) packs a sequence into a power series. Ordinary ( 普通型 , OGF): A(x) = Σ
anxn; multiplying OGFs counts combinations: picking 0 … ci items of type i is (1 + x + … + xci), and the
product's xn coefficient counts the ways to pick n items in total.
KEY POINT Exponential ( 指数型 , EGF): A(x) = Σ anxn/n!; multiplying EGFs counts arrangements (labelled objects,
strings): a letter used k times contributes xk/k!, and n! times the xn coefficient counts strings of length n.
Taylor series give closed forms: Σ xk = 1/(1 − x), Σ xk/k! = eˣ, even k: (eˣ + e⁻ˣ)/2.
ogf.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 int main() {
5     int k, n;
6     cin >> k >> n;
7     vector<long long> poly(n + 1, 0);
8     poly[0] = 1;                                  // the empty product
9     for (int t = 0; t < k; t++) {
10         int c; cin >> c;                          // type t: 0..c copies
11         vector<long long> next(n + 1, 0);
12         for (int i = 0; i <= n; i++)
13             for (int j = 0; j <= c && i + j <= n; j++) next[i + j] += poly[i];   // multiply by 1 + x + 
... + x^c
14         poly = next;
15     }
16     cout << poly[n] << "\n";                      // coefficient of x^n
17     return 0;
18 }

1 #include <bits/stdc++.h>

4 const long long MOD = 1000000007;
5 long long power(long long a, long long b) { long long r = 1; for (a %= MOD; b; b >>= 1, a = a * a % MOD) 
if (b & 1) r = r * a % MOD; return r; }
6  
7 int main() {
8     int n;
9     cin >> n;
10     vector<long long> fact(n + 1, 1), inv(n + 1, 1);
11     for (int i = 1; i <= n; i++) fact[i] = fact[i - 1] * i % MOD;
12     for (int i = 0; i <= n; i++) inv[i] = power(fact[i], MOD - 2);
13     vector<long long> A(n + 1, 0), B(n + 1, 0), C(n + 1, 0);
14     for (int k = 0; k <= n; k++) {
15         if (k % 2 == 0) A[k] = inv[k];             // 'a': even number of times
16         if (k >= 1) B[k] = inv[k];                 // 'b': at least once
17         C[k] = inv[k];                             // 'c': any number of times
18     }
19     vector<long long> AB(n + 1, 0), ABC(n + 1, 0);
20     for (int i = 0; i <= n; i++) for (int j = 0; i + j <= n; j++) AB[i + j] = (AB[i + j] + A[i] * B[j]) 
% MOD;
21     for (int i = 0; i <= n; i++) for (int j = 0; i + j <= n; j++) ABC[i + j] = (ABC[i + j] + AB[i] * 
C[j]) % MOD;
22     cout << ABC[n] * fact[n] % MOD << "\n";        // n! times the x^n coefficient
23     return 0;
24 }

KEY POINT OGF: ways to pick 6 items when the four types allow at most 2, 3, 1, 4 copies; EGF: strings of length 6 over
{a, b, c} with an even number of a's and at least one b. Both are checked by brute force in Python. Products
of large series use FFT / NTT ( 第 8 章 ).
31.3 P/N	 状态、巴什游戏与置换群
Backward	tables;	Bash	game;	cycles.
IDEA P-positions	and	N-positions: a position is P (the Previous player, who just moved, wins) when every
move leads to an N-position; it is N (the Next player wins) when some move leads to a P-position.
Terminal positions are P. Filling this table backwards is the basic method for any small game (and SG = 0
⇔ P, 第 10 章 ).
KEY POINT Bash	game ( 巴什游戏 ): one pile of n stones, take 1 … m per move, taking the last stone wins. P-positions
are exactly the multiples of m + 1: from a multiple, every move leaves a non-multiple; from a non-
multiple, taking n mod (m + 1) leaves a multiple. So the first player wins iff n mod (m + 1) ≠ 0.

KEY POINT The table for moves {1, 3, 4} shows P-positions at 0, 2, 7, 9, 14, 16, …: period 7. Tabulating, then spotting
the period, is how most "formula" games are discovered.
IDEA A permutation	group ( 置换群 ) is a set of permutations closed under composition, containing the
identity and inverses (rotations of a necklace, rotations and reflections of a square). Every permutation
splits into disjoint cycles; a colouring is fixed by a permutation iff each cycle is single-coloured, so it fixes
m(number of cycles) colourings. That is the input to Burnside / Pólya ( 第 23 章 ).
KEY POINT Rotation by k of n positions has gcd(k, n) cycles, each of length n / gcd(k, n). A reflection of an n-gon has
(n + 1)/2 cycles for odd n; for even n, half the reflections have n/2 cycles and half have n/2 + 1.

31.4 课后习题与实验
The	Luogu	problems	for	this	chapter,	a	ladder	through	them,	and	experiments	to	try	yourself.
Key	points	to	memorise
1. Pigeonhole: n + 1 objects, n boxes ⇒ a shared box; kn + 1 ⇒ k + 1.
2. Prefix remainders mod n repeat ⇒ a block divisible by n.
3. OGF: product of (1 + x + … + x^c) counts combinations.
4. EGF: terms x^k/k!; n!·[x^n] counts arrangements.
5. P: all moves to N; N: some move to P; terminal = P.
6. Bash (take 1…m): P ⇔ n ≡ 0 (mod m + 1).
7. Permutation = disjoint cycles; fixed colourings m^(cycles).
