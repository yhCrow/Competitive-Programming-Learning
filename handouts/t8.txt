8.1 快速傅里叶变换
Evaluate,	multiply,	interpolate;	the	butterfly.
coefficients values at ωᵏ product values
FFT multiply
inverse FFT: back to coefficients
IDEA Multiplying two polynomials of degree
n directly is O(n²). But a polynomial of
degree < N is fixed by its values at N
points, and values	multiply	point	by
point. So: evaluate both at N special
points, multiply the values, and turn the
products back into coefficients. FFT ( 快
速傅里叶变换 ) does the evaluation and
its inverse in O(N log N).
KEY POINT The special points are the N-th roots of
unity ωk. Splitting A(x) = Aeven(x²) +
x·Aodd(x²) halves the problem, because
the squares of the N roots are the N/2
roots, each twice. The inverse transform
is the same algorithm with ω⁻¹, divided
by N.
竞 赛 拓 展 专 题  · 拓 展 篇  · 数 学 拓 展
Multiply polynomials in O(n log n) by evaluating at roots of unity, multiplying values and transforming
back; NTT does the same exactly modulo a prime, for big numbers and every convolution.

1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 typedef complex<double> cd;
5 const double PI = acos(-1.0);
6  
7 void fft(vector<cd> &a, bool invert) {
8     int n = a.size();
9     for (int i = 1, j = 0; i < n; i++) {               // bit-reversal order: leaves of the recursion
10         int bit = n >> 1;
11         for (; j & bit; bit >>= 1) j ^= bit;
12         j ^= bit;
13         if (i < j) swap(a[i], a[j]);
14     }
15     for (int len = 2; len <= n; len <<= 1) {           // combine halves of size len / 2
16         double ang = 2 * PI / len * (invert ? -1 : 1);
17         cd wl(cos(ang), sin(ang));
18         for (int i = 0; i < n; i += len) {
19             cd w(1);
20             for (int j = 0; j < len / 2; j++) {
21                 cd u = a[i + j], v = a[i + j + len / 2] * w;   // butterfly
22                 a[i + j] = u + v;
23                 a[i + j + len / 2] = u - v;
24                 w *= wl;
25             }
26         }
27     }
28     if (invert) for (int i = 0; i < n; i++) a[i] /= n;
29 }
30  
31 int main() {
32     int n, m;
33     cin >> n >> m;                                     // degrees
34     int N = 1;
35     while (N < n + m + 1) N <<= 1;                     // room for the product, power of two
36     vector<cd> a(N), b(N);
37     for (int i = 0; i <= n; i++) { int x; cin >> x; a[i] = x; }
38     for (int i = 0; i <= m; i++) { int x; cin >> x; b[i] = x; }
39     fft(a, false); fft(b, false);
40     for (int i = 0; i < N; i++) a[i] *= b[i];          // multiply the values
41     fft(a, true);
42     for (int i = 0; i <= n + m; i++) cout << llround(a[i].real()) << " ";   // round off errors
43     cout << "\n";
44     return 0;
45 }

KEY POINT (1 + 2x)(1 + 2x + x²) = 1 + 4x + 5x² + 2x³ (P3803). The size N must be a power of two of at least n + m + 1,
and results are rounded with llround because doubles carry small errors.
TRAP Floating-point FFT loses precision when coefficients or N are large (products near 10¹⁵ and beyond). For
exact answers modulo a prime, use NTT (8.2); for an arbitrary modulus, split numbers into 15-bit halves
or use three NTT primes (P4245).

8.2 快速数论变换与卷积
NTT	mod	998244353;	big-number	multiplication.
IDEA NTT ( 快速数论变换 ) is FFT done modulo a prime p = c·2k + 1, such as 998244353 = 119·2²³ + 1. A
primitive root g (3 for 998244353) gives g(p−1)/N, which behaves exactly like an N-th root of unity mod p.
Same code, integer arithmetic, no rounding errors.
KEY POINT Convolution is everywhere: big-number multiplication (digits as coefficients, P1919), counting pairs with
a given sum, matching with wildcards, and the "force" sums of P3338 after reversing one array. Whenever
ck = Σi+j=k aibj appears, think convolution.

1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 const long long MOD = 998244353, G = 3;
5  
6 long long power(long long a, long long b) {
7     long long r = 1;
8     for (a %= MOD; b > 0; b >>= 1, a = a * a % MOD) if (b & 1) r = r * a % MOD;
9     return r;
10 }
11  
12 void ntt(vector<long long> &a, bool invert) {
13     int n = a.size();
14     for (int i = 1, j = 0; i < n; i++) {
15         int bit = n >> 1;
16         for (; j & bit; bit >>= 1) j ^= bit;
17         j ^= bit;
18         if (i < j) swap(a[i], a[j]);
19     }
20     for (int len = 2; len <= n; len <<= 1) {
21         long long wl = power(G, (MOD - 1) / len);      // a len-th root of unity mod p
22         if (invert) wl = power(wl, MOD - 2);
23         for (int i = 0; i < n; i += len) {
24             long long w = 1;
25             for (int j = 0; j < len / 2; j++) {
26                 long long u = a[i + j], v = a[i + j + len / 2] * w % MOD;
27                 a[i + j] = (u + v) % MOD;
28                 a[i + j + len / 2] = (u - v + MOD) % MOD;
29                 w = w * wl % MOD;
30             }
31         }
32     }
33     if (invert) {
34         long long inv = power(n, MOD - 2);
35         for (int i = 0; i < n; i++) a[i] = a[i] * inv % MOD;
36     }
37 }

8.3 课后习题与实验
The	Luogu	problems	for	this	chapter,	a	ladder	through	them,	and	experiments	to	try	yourself.
Key	points	to	memorise
1. Values at N points determine a degree < N polynomial; values multiply pointwise.
2. FFT: split even / odd; roots of unity square to half as many roots; O(N log N).
3. Iterative: bit-reversal order, then butterflies u ± w·v for len = 2, 4, ….
4. Inverse: ω⁻¹ and divide by N. N = power of two ≥ n + m + 1.
5. NTT: p = 998244353, g = 3, root g^((p−1)/len); exact, no rounding.
6. c_k = Σ_{i+j=k} a_i b_j ⇒ convolution; reverse an array for differences i − j.
