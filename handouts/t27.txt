27.1 Tarjan	 离线求 	LCA
Join	finished	vertices;	find	answers.
IDEA Tarjan's	offline	LCA answers all LCA queries in one DFS with a DSU, O((n + q) α(n)). When the DFS
finishes a vertex, join it to its parent in the DSU. For a query (u, v): when the DFS is at u and v is already
finished, LCA(u, v) = find(v), the highest ancestor of v whose subtree the DFS is still inside.
KEY POINT It needs all queries in advance (offline). Binary lifting ( 进阶篇  第 9 章 ) is online and easier to reuse; Tarjan
is the fastest when there are millions of queries.
竞 赛 拓 展 专 题  · 拓 展 篇  · 图 论 补 充
Answer all LCA queries offline with a DSU, solve graphs with exactly one cycle by cutting it, find SCCs with
two DFS passes, and keep centroid ancestors for dynamic path queries.

5 vector<int> g[N];

7 int fa[N], ans[N];
8 bool done[N];
9 int find(int x) { return fa[x] == x ? x : fa[x] = find(fa[x]); }

11 void dfs(int u, int p) {
12     for (int k = 0; k < int(g[u].size()); k++) {
13         int v = g[u][k];
14         if (v == p) continue;
15         dfs(v, u);
16         fa[v] = u;                                // v finished: join it to its parent
17     }
18     done[u] = true;
19     for (int k = 0; k < int(qs[u].size()); k++) {
20         int v = qs[u][k].first;
21         if (done[v]) ans[qs[u][k].second] = find(v);
22     }
23 }

27.2 基环树
One	cycle:	cut	an	edge,	DP	twice.
IDEA A pseudotree ( 基环树 ) is a connected graph with n vertices and n edges: a tree plus one extra edge, so
exactly one	cycle. When every vertex has exactly one outgoing edge (a functional graph, "each knight hates
one other"), every component is a pseudotree. The standard trick: find the cycle, cut	one	cycle	edge (u,
v), and solve a tree problem with u or v forced.
KEY POINT Knights ( 骑士  P2607): choose a maximum-power set with no hating pair. After cutting the cycle edge (u,
v), run the "party" tree DP ( 进阶篇  第 16 章 ) twice: once forbidding u, once forbidding v; the better of the
two respects the cut edge. Sum over components.

pseudotree.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 const int N = 1000005;
5 int n, hate[N], cu, cv, cutId;
6 long long w[N], f[N][2];
7 vector<pair<int, int>> g[N];                     // (neighbour, edge id)
8 bool vis[N];
9  
10 void findCycle(int u, int fromEdge) {            // any edge reaching a visited vertex closes the cycle
11     vis[u] = true;
12     for (int k = 0; k < int(g[u].size()); k++) {
13         int v = g[u][k].first, id = g[u][k].second;
14         if (id == fromEdge) continue;
15         if (vis[v]) { cu = u; cv = v; cutId = id; }
16         else findCycle(v, id);
17     }
18 }
19 void dp(int u, int fromEdge) {
20     f[u][0] = 0; f[u][1] = w[u];
21     for (int k = 0; k < int(g[u].size()); k++) {
22         int v = g[u][k].first, id = g[u][k].second;
23         if (id == fromEdge || id == cutId) continue;   // the cut edge does not exist
24         dp(v, id);
25         f[u][0] += max(f[v][0], f[v][1]);
26         f[u][1] += f[v][0];
27     }
28 }
29  
30 int main() {
31     cin >> n;
32     for (int i = 1; i <= n; i++) {
33         cin >> w[i] >> hate[i];
34         g[i].push_back(make_pair(hate[i], i));      // edge id = i (one per knight)
35         g[hate[i]].push_back(make_pair(i, i));
36     }
37     long long total = 0;
38     for (int i = 1; i <= n; i++) {
39         if (vis[i]) continue;
40         cutId = -1;
41         findCycle(i, 0);
42         dp(cu, 0); long long a = f[cu][0];          // cu not chosen
43         dp(cv, 0); long long b = f[cv][0];          // cv not chosen
44         total += max(a, b);
45     }
46     cout << total << "\n";
47     return 0;
48 }

27.3 Kosaraju	 算法
Finish	order,	then	the	reversed	graph.
IDEA Kosaraju's	algorithm finds SCCs with two DFS passes: (1) DFS the graph, recording vertices in order of
finishing; (2) DFS the reversed graph, starting from vertices in decreasing finish time; each DFS of pass 2
collects exactly one SCC.
KEY POINT Why it works: the vertex that finishes last lies in a "source" SCC; in the reversed graph nothing leaves that
SCC, so pass 2 cannot spill into another one. Tarjan ( 进阶篇  第 12 章 ) does it in one pass; Kosaraju is easier
to remember and also gives the SCCs in topological order.
kosaraju.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 const int N = 100005;
5 vector<int> g[N], rg[N], order_;
6 int comp[N], cnt = 0;
7 bool vis[N];
8  
9 void dfs1(int u) { vis[u] = true; for (int k = 0; k < int(g[u].size()); k++) if (!vis[g[u][k]]) 
dfs1(g[u][k]); order_.push_back(u); }
10 void dfs2(int u, int c) { comp[u] = c; for (int k = 0; k < int(rg[u].size()); k++) if (!comp[rg[u][k]]) 
dfs2(rg[u][k], c); }
11  
12 int main() {
13     int n, m;
14     cin >> n >> m;
15     for (int i = 0; i < m; i++) { int a, b; cin >> a >> b; g[a].push_back(b); rg[b].push_back(a); }
16     for (int i = 1; i <= n; i++) if (!vis[i]) dfs1(i);
17     for (int i = n - 1; i >= 0; i--) if (!comp[order_[i]]) dfs2(order_[i], ++cnt);   // latest finish 
first
18     vector<int> sz(cnt + 1, 0);
19     for (int i = 1; i <= n; i++) sz[comp[i]]++;
20     sort(sz.begin() + 1, sz.end());
21     cout << cnt << "\n";
22     for (int c = 1; c <= cnt; c++) cout << sz[c] << (c < cnt ? " " : "");
23     cout << "\n";
24     return 0;
25 }

27.4 动态点分治
Centroid	tree;	O(log	n)	ancestors.
IDEA Dynamic	centroid	decomposition ( 动态点分治  / 点分树 ): record, for every vertex, its parent in the
centroid recursion ( 第 6 章 ). This "centroid tree" has depth O(log n), and every path u–v in the original tree
passes through LCAcentroid tree(u, v). So a query about all vertices near u only looks at u's O(log n)
centroid ancestors, and an update changes data at those same ancestors.
KEY POINT At each centroid c keep a data structure of its subtree indexed by distance to c (a Fenwick tree), plus a
second one indexed by distance to c's centroid parent, to subtract the part counted twice. Each query /
update: O(log² n) ( 震波  P6329: sum of values within distance k, with point updates).
TRAP Distances in the centroid tree are not tree distances; always use the original tree distance (precomputed
with LCA) between u and each centroid ancestor.
27.5 课后习题与实验
The	Luogu	problems	for	this	chapter,	a	ladder	through	them,	and	experiments	to	try	yourself.
Key	points	to	memorise
1. Tarjan LCA: after finishing v, fa[v] = parent; query answer = find(other) if done.
2. Pseudotree: n vertices, n edges, one cycle; functional graphs are forests of them.
3. Cut a cycle edge (u, v); tree DP forbidding u, then forbidding v.
4. Kosaraju: finish order on G, then DFS on reversed G by decreasing finish time.
5. Centroid tree depth O(log n); path u–v passes their centroid-tree LCA.
