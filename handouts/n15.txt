15.1 类欧几里得
Pull	out	whole	parts,	then	swap	axes.
IDEA Floor	sums ( 类欧几里得 ): f(a, b, c, n) = Σi=0..n ⌊(a·i + b)/c⌋ in O(log) time. If a ≥ c or b ≥ c, pull out the
whole parts: ⌊a/c⌋·n(n+1)/2 + ⌊b/c⌋·(n + 1) + f(a mod c, b mod c, c, n). Otherwise, with m = ⌊(a·n + b)/c⌋,
count lattice points the other way: f = n·m − f(c, c − b − 1, a, m − 1). The parameters shrink like Euclid's
algorithm.
KEY POINT It counts lattice points under a line, so it appears in sums like Σ ⌊(ai + b)/c⌋, Σ i·⌊…⌋ and Σ ⌊…⌋² (the full
P5170 asks for all three with a joint recursion), and in counting integer points in triangles and under lines
with rational slopes.
竞 赛 拓 展 专 题  · NOI 篇  · NOI 专 题
Sum floors of linear functions in logarithmic time, find generators modulo a prime, take square roots
modulo p with Cipolla, and count lattice points with Pick's theorem.

4 typedef long long ll;
5 ll f(ll a, ll b, ll c, ll n) {                       // sum_{i=0..n} floor((a i + b) / c)
6     if (a == 0) return (b / c) * (n + 1);
7     if (a >= c || b >= c)
8         return (a / c) * n * (n + 1) / 2 + (b / c) * (n + 1) + f(a % c, b % c, c, n);
9     ll m = (a * n + b) / c;
10     return n * m - f(c, c - b - 1, a, m - 1);        // swap the roles of the axes
11 }

15.2 原根
g^((p−1)/q)	≠	1	for	every	prime	q	|	p	−	1.
IDEA A primitive	root ( 原根 ) g modulo a prime p generates every non-zero residue: g, g², …, gp−1 are all
different. Then every x ≠ 0 is gk for a unique k (its discrete log), which turns multiplication into addition
( 序列统计  in 拓展篇  第 8 章 , and NTT's g = 3 for 998244353).
KEY POINT Test a candidate g: g is a primitive root iff g(p−1)/q ≠ 1 for every prime factor q of p − 1. Primitive roots are
common (φ(p − 1) of them), so trying g = 2, 3, … finds the smallest quickly. Primitive roots exist exactly
for 1, 2, 4, pᵏ and 2pᵏ (P6091 lists all of them).

15.3 二次剩余
Euler's	criterion;	Cipolla	in	u	+	vω.
IDEA A quadratic	residue ( 二次剩余 ) modulo an odd prime p is n with x² ≡ n solvable. Euler's criterion:
n(p−1)/2 ≡ 1 if it is a residue, −1 if not. Cipolla's	algorithm finds x: pick random a with a² − n a non-
residue (half of all a work), set ω² = a² − n, and compute (a + ω)(p+1)/2 in the field of numbers u + vω. The
result has v = 0 and is a square root of n (P5491).
KEY POINT The two roots are x and p − x. Arithmetic in u + vω: (u₁ + v₁ω)(u₂ + v₂ω) = (u₁u₂ + v₁v₂ω²) + (u₁v₂ +
u₂v₁)ω.

8 C mul(C x, C y) { return C{(x.u * y.u + x.v * y.v % p * w2) % p, (x.u * y.v + x.v * y.u) % p}; }
9  
10 int main() {
11     int T;
12     cin >> T;

16         n %= p;
17         if (n == 0) { cout << 0 << "\n"; continue; }
18         if (power(n, (p - 1) / 2) != 1) { cout << "Hola!\n"; continue; }   // Euler's criterion
19         ll a;
20         while (true) {
21             a = rng() % p;
22             w2 = ((a * a - n) % p + p) % p;

15.4 皮克定理
A	=	I	+	B/2	−	1;	boundary	by	gcd.
IDEA Pick's	theorem ( 皮克定理 ): for a polygon whose vertices are lattice points, area = I + B/2 − 1, where I is
the number of lattice points strictly inside and B the number on the boundary. A segment from (x₁, y₁) to
(x₂, y₂) contains gcd(|x₂ − x₁|, |y₂ − y₁|) + 1 lattice points, so B is a sum of gcds and I follows from the
shoelace area.

15.5 万能欧几里得
U/R	walk	under	a	line;	any	monoid.
IDEA Universal	Euclid ( 万能欧几里得 ): walk along the line y = (p·x + r) / q for x = 1..n and write "U" each time
y passes an integer and "R" at each integer x. The string of U's and R's is built by a Euclid-like recursion in
O(log) multiplications, if the quantity you want is a monoid: a node that knows how to combine two
pieces of the walk.
KEY POINT 类欧几里得  ( 第 1 节 ) needs a new formula for every sum; universal Euclid needs only the merge rule.
Below, a node stores (#R, #U, Σy, Σx·y) over its R steps; merging shifts the right part by the left part's
counts. Matrices also form a monoid, which gives Σ Ax B⌊(px+r)/q⌋.

universal_euclid.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 typedef long long ll;
5 struct Node { ll x, y, sy, sxy; };                  // #R, #U, sum of y, sum of x*y (over R steps)
6 Node operator*(Node a, Node b) {
7     Node c;
8     c.x = a.x + b.x; c.y = a.y + b.y;
9     c.sy = a.sy + b.sy + a.y * b.x;
10     c.sxy = a.sxy + b.sxy + a.x * b.sy + a.y * (b.x * (b.x + 1) / 2) + a.x * a.y * b.x;
11     return c;
12 }
13 Node pw(Node a, ll e) { Node r = {0, 0, 0, 0}; while (e) { if (e & 1) r = r * a; a = a * a; e >>= 1; } 
return r; }
14  
15 Node solve(ll p, ll q, ll r, ll l, Node U, Node R) {   // y = (p x + r) / q, x = 1..l, 0 <= r < q
16     if (!l) return {0, 0, 0, 0};
17     if (p >= q) return solve(p % q, q, r, l, U, pw(U, p / q) * R);
18     ll m = (__int128(p) * l + r) / q;
19     if (!m) return pw(R, l);
20     ll cnt = l - (__int128(q) * m - r - 1) / p;
21     return pw(R, (q - r - 1) / p) * U * solve(q, p, (q - r - 1) % p, m - 1, R, U) * pw(R, cnt);
22 }
23  
24 int main() {
25     int T;
26     cin >> T;
27     for (int i = 0; i < T; i++) {
28         ll p, q, r, n;
29         cin >> p >> q >> r >> n;
30         Node U = {0, 1, 0, 0}, R = {1, 0, 0, 0};
31         Node res = solve(p, q, r, n, U, R);
32         cout << res.sy << " " << res.sxy << "\n";
33     }
34     return 0;
35 }

Key	points	to	memorise
1. Floor sum: a ≥ c or b ≥ c ⇒ split off whole parts; else n·m − f(c, c−b−1, a, m−1).
2. Primitive root test: g^((p−1)/q) ≠ 1 for all prime q | p − 1.
3. Euler: n^((p−1)/2) = ±1 (residue / non-residue).
4. Cipolla: ω² = a² − n non-residue; (a + ω)^((p+1)/2).
5. Pick: A = I + B/2 − 1; segment points = gcd + 1.
6. Universal Euclid: U/R string of the line, built recursively with fast powers of monoid nodes.
