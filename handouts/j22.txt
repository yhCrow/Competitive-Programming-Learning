IDEA A vector is a list of numbers; an n × n
matrix maps vectors to vectors. The
product C = A·B has C[i][j] = Σk A[i]
[k]·B[k][j], O(n³). It is associative,
(AB)C = A(BC), but not commutative, so
Aⁿ can be computed by repeated
squaring like a number ( 第 3 章 ): O(n³
log N).
KEY POINT Matrix	acceleration ( 矩阵加速 ): if the
next state vector is a fixed linear
function of the current one, write that
function as a matrix M; then stateN =
MN·state0. A recurrence with N = 10¹⁸
steps becomes about 60 squarings.
深 入 浅 出 程 序 设 计 竞 赛  · 进 阶 篇  · 第 5 部 分  数 学 专 题 选 讲
Matrices turn linear recurrences into fast powers and chains of geometric moves into one product;
Gaussian elimination solves linear systems and computes determinants.

IDEA Fibonacci (P1962): (Fn+1, Fn) = M·(Fn, Fn−1) with M = [[1, 1], [1, 0]]. Starting from (F1, F0) = (1, 0), Mn−1

16 int main() {
17     int n, q;
18     cin >> n >> q;
19     vector<long long> x(n), y(n);
20     for (int i = 0; i < n; i++) cin >> x[i] >> y[i];
21     Mat total = {{{1, 0, 0}, {0, 1, 0}, {0, 0, 1}}};
22     while (q--) {
23         char op;
24         cin >> op;
25         Mat t = {{{1, 0, 0}, {0, 1, 0}, {0, 0, 1}}};
26         if (op == 'M') { cin >> t.a[0][2] >> t.a[1][2]; }                     // move by (dx, dy)
27         else if (op == 'S') { long long k; cin >> k; t.a[0][0] = t.a[1][1] = k; }   // scale
28         else { t.a[0][0] = 0; t.a[0][1] = -1; t.a[1][0] = 1; t.a[1][1] = 0; }  // rotate 90 degrees
29         total = mul(t, total);              // the new operation acts AFTER the earlier ones
30     }
31     for (int i = 0; i < n; i++)             // (x, y, 1) -> total * (x, y, 1)
32         cout << total.a[0][0] * x[i] + total.a[0][1] * y[i] + total.a[0][2] << " "
33              << total.a[1][0] * x[i] + total.a[1][1] * y[i] + total.a[1][2] << "\n";

IDEA Points as vectors (x, y, 1): the extra 1 lets a 3 × 3 matrix also translate. Rotation by 90° maps (x, y) to (−y,
x); scaling multiplies both by k. A whole sequence of operations collapses into one matrix, applied to
every point in O(1).
KEY POINT Order matters: a later operation T is multiplied on the left, total = T·total. Rotating then moving (1, 0)
gives (0, 1) then (1, 2); moving first would give a different point. Many queries over ranges of operations
combine these matrices in a segment tree.

22.2 高斯消元
Solving	systems;	no	/	infinite	solutions;	determinants	mod	p.
2 1 -1 8
-3 -1 2 -11
-2 1 2 -3
→
1 0 0 2
0 1 0 3
0 0 1 -1
x = 2, y = 3, z = −1
IDEA Gaussian	elimination ( 高斯消元 )
solves n linear equations in n unknowns
in O(n³). For each column c: pick a row
with a non-zero entry in column c (the
pivot, take the largest absolute value for
accuracy), swap it up, divide it by the
pivot, and subtract multiples of it from
every other row so column c becomes 0
elsewhere.
KEY POINT At the end each variable sits alone in its
row (Gauss-Jordan form) and the last
column holds the answer. A column
with no usable pivot means the system
has either no solution (some row reads
0 = non-zero) or infinitely many.

1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 const double EPS = 1e-8;
5 double a[55][55];
6  
7 int main() {
8     int n;
9     cin >> n;
10     for (int i = 0; i < n; i++)
11         for (int j = 0; j <= n; j++) cin >> a[i][j];     // last column: right-hand side
12     int row = 0;
13     for (int col = 0; col < n && row < n; col++) {
14         int p = row;
15         for (int i = row; i < n; i++) if (fabs(a[i][col]) > fabs(a[p][col])) p = i;   // largest pivot
16         if (fabs(a[p][col]) < EPS) continue;             // no pivot: a free variable
17         for (int j = 0; j <= n; j++) swap(a[p][j], a[row][j]);
18         double piv = a[row][col];
19         for (int j = col; j <= n; j++) a[row][j] /= piv;
20         for (int i = 0; i < n; i++)
21             if (i != row && fabs(a[i][col]) > EPS) {
22                 double f = a[i][col];
23                 for (int j = col; j <= n; j++) a[i][j] -= f * a[row][j];
24             }
25         row++;
26     }
27     for (int i = row; i < n; i++)                        // rows that became all zero on the left
28         if (fabs(a[i][n]) > EPS) { cout << -1 << "\n"; return 0; }   // 0 = non-zero: no solution
29     if (row < n) { cout << 0 << "\n"; return 0; }        // a free variable: infinitely many
30     for (int i = 0; i < n; i++) cout << "x" << i + 1 << "=" << fixed << setprecision(2) << a[i][n] << 
"\n";
31     return 0;
32 }

22.2.1 Elimination	with	other	arithmetic
determinant.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 long long a[605][605];
5  
6 int main() {
7     int n;
8     long long p;
9     cin >> n >> p;
10     for (int i = 0; i < n; i++)
11         for (int j = 0; j < n; j++) { cin >> a[i][j]; a[i][j] %= p; }
12     long long det = 1;
13     for (int c = 0; c < n; c++) {
14         for (int i = c + 1; i < n; i++) {
15             while (a[i][c] != 0) {                      // Euclid on rows c and i: no inverses needed
16                 long long t = a[c][c] / a[i][c];
17                 for (int j = c; j < n; j++) a[c][j] = ((a[c][j] - t * a[i][j]) % p + p) % p;
18                 for (int j = c; j < n; j++) swap(a[c][j], a[i][j]);
19                 det = (p - det) % p;                    // a row swap flips the sign
20             }
21         }
22         det = det * a[c][c] % p;                        // triangular: product of the diagonal
23     }
24     cout << det << "\n";
25     return 0;
26 }

IDEA The determinant ( 行列式 , P7112) is the product of the diagonal after elimination to a triangle, with a
sign flip per row swap. Modulo a non-prime p you cannot divide, so eliminate two rows against each
other like Euclid's algorithm: subtract ⌊x / y⌋ times, swap, repeat. Total O(n²(n + log p)).
KEY POINT [[1, 2], [3, 4]] has determinant 1·4 − 2·3 = −2 ≡ 998244351. Over GF(2) (P2447 外星千足虫 , lights-out
puzzles) elimination uses XOR on rows stored as bitset : 64 times faster.
KEY POINT Systems you have to build first: points on a sphere (P4035) give linear equations after subtracting pairs of
"distance to the centre is r" equations; expected values on a graph with cycles (P2973) are n equations E =
Σ p·E′ solved by elimination.

Key	points	to	memorise
1. C[i][j] = Σ A[i][k]·B[k][j]; associative, not commutative.
2. Linear recurrence: state vector + one matrix row per entry; Mᴺ by squaring.
3. Identity matrix = the 1 of fast power. Walks of length N = adjacency matrix ^ N.
4. Homogeneous (x, y, 1): rotate, scale and translate as 3 × 3 matrices; later ops multiply on the left.
5. Gauss: largest pivot, swap, normalise, clear the column in every other row; O(n³).
6. Contradicting row ⇒ no solution (check first); missing pivot ⇒ infinitely many.
7. Determinant = ± product of the diagonal after elimination; mod non-prime: Euclid on rows.
