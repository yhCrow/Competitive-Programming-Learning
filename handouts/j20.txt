IDEA Inclusion-exclusion ( 容斥原理 ): to
count objects with at least one bad
property, add the single properties,
subtract the pairs (counted twice), add
the triples back, and so on: Σ over non-
empty sets S of properties, (−1)|S|+1 ·
(number having all of S).
KEY POINT Usually you want the objects with no
bad property: total − |A ∪ B ∪ …| = Σ
over all S (including ∅) of (−1)|S| · N(S).
The art is choosing properties whose
intersections are easy to count. Often
the simplest form is the complement
with a single property.

IDEA Prison break (P3197): count rows of n cells, each with one of m religions, where some two neighbours
share a religion. Counting "some" directly is messy; its complement "no two neighbours equal" is m·(m −
1)n−1 (the first cell is free, every later one avoids its left neighbour).
KEY POINT Subtract under a modulus with + MOD. n, m reach 10¹², so reduce m before multiplying and use fast
power.

4 const long long MOD = 1000000007;
5 const int N = 1000005;
6 long long fact[N], inv[N], D[N];
7  
8 long long power(long long a, long long b) {
9     long long r = 1;
10     for (a %= MOD; b > 0; b >>= 1, a = a * a % MOD) if (b & 1) r = r * a % MOD;
11     return r;
12 }
13  
14 long long C(int n, int m) { return m < 0 || m > n ? 0 : fact[n] * inv[m] % MOD * inv[n - m] % MOD; }
15  
16 int main() {
17     fact[0] = 1;
18     for (int i = 1; i < N; i++) fact[i] = fact[i - 1] * i % MOD;
19     inv[N - 1] = power(fact[N - 1], MOD - 2);
20     for (int i = N - 1; i > 0; i--) inv[i - 1] = inv[i] * i % MOD;    // inverse factorials
21     D[0] = 1; D[1] = 0;
22     for (int i = 2; i < N; i++) D[i] = (i - 1) * (D[i - 1] + D[i - 2]) % MOD;
23     int T;
24     cin >> T;
25     while (T--) {
26         int n, m;
27         cin >> n >> m;                               // exactly m fixed points
28         cout << C(n, m) * D[n - m] % MOD << "\n";
29     }
30     return 0;
31 }

IDEA A derangement ( 错排 ) moves every element. By inclusion-exclusion over "i stays put": D(n) = Σk (−1)k
C(n, k)(n − k)!. The same numbers satisfy D(n) = (n − 1)(D(n − 1) + D(n − 2)), which is faster to fill.
KEY POINT Exactly m fixed points (P4071): choose them, C(n, m), and derange the rest: D(n − m). 1, 0, 1, 2, 9, 44 are
D(0) … D(5). Inverse factorials are filled backwards from one Fermat inverse ( 第 19 章 ).

IDEA Combinations C(n, m) ( 组合数 ) count
ways to choose m of n items. Three
ways to get them: Pascal's	rule C(n, m)
= C(n−1, m−1) + C(n−1, m) for a whole
table up to about 2000 (any modulus,
even none); factorials n! / (m!(n−m)!)
with inverse factorials for n up to 10⁶
and a prime modulus; Lucas when n is
huge and the prime p is small.
KEY POINT Pascal's rule reads: either the last item
is chosen (choose m − 1 from the rest)
or it is not (choose m from the rest).
This "last item" argument is the start of
most counting recurrences.
Model Count Example
ordered, no repeats n! / (n − m)! podium of m from n runners
unordered, no repeats C(n, m) committee of m
n identical balls into m boxes, empty allowed C(n + m − 1, m − 1) stars and bars ( 插板法 )
same, every box non-empty C(n − 1, m − 1) cuts between n balls
keep some items apart arrange the others, insert into the gaps 插空法  (P3223 排队 )
multiset permutations n! / (a! b! …) arrangements of a word

IDEA Combination problem (P2822): for many (n, m), count pairs 0 ≤ j ≤ i ≤ n, j ≤ m with k | C(i, j). C(i, j) is
huge, but divisibility by k only needs it mod	k, and Pascal's rule works mod anything. Then a 2D prefix
sum answers each query in O(1).
KEY POINT For k = 2, n = m = 3 the rows are 1; 1 1; 1 2 1; 1 3 3 1, and only C(2, 1) = 2 is even: answer 1. Store only
remainders: the real values overflow long long by row 70.
TRAP Query column min(n, m): there are no C(i, j) with j > i, and the prefix sums already count those cells as 0.
20.3 二项式定理
Coefficients	of	(ax	+	by)^k.
IDEA Binomial	theorem ( 二项式定理 ): (a + b)n = Σk=0..n C(n, k) ak bn−k. Each of the n brackets gives either a
or b; choosing which k brackets give a is C(n, k). Setting a = b = 1 gives Σ C(n, k) = 2ⁿ; a = 1, b = −1 gives the
alternating sum 0.
KEY POINT Coefficients of polynomials are counting problems in disguise: the coefficient of xk in a product counts
ways to pick one term from each factor with exponents adding to k.

20.4 卡特兰数与斯特林数
Stack	orders;	balls	into	boxes.
IDEA Catalan	numbers ( 卡特兰数 ) 1, 1, 2, 5, 14, 42, … count: push/pop orders of a stack (P1044), balanced
bracket strings, binary trees with n nodes, monotone lattice paths that never cross the diagonal, ways to
triangulate a polygon. Cat(n) = C(2n, n) / (n + 1) = C(2n, n) − C(2n, n − 1).
KEY POINT Recurrence by the first	return: the first element pushed is popped after k others were pushed and popped
inside it: Cat(n) = Σk=0..n−1 Cat(k)·Cat(n − 1 − k). The subtraction form comes from reflecting the bad
paths at the first crossing.

KEY POINT Stirling	numbers	of	the	second	kind ( 第二类斯特林数 ) S(n, k) count ways to split n distinct items into
k non-empty unlabelled groups: the last item either forms its own group, S(n−1, k−1), or joins one of the

20.5 课后习题与实验
The	Luogu	problems	for	this	chapter,	a	ladder	through	them,	and	experiments	to	try	yourself.
Key	points	to	memorise
1. Complement first: bad = all − good.
2. Inclusion-exclusion: Σ over sets S of (−1)^|S| · N(S).
3. Derangements: D(n) = (n − 1)(D(n − 1) + D(n − 2)); exactly m fixed: C(n, m)·D(n − m).
4. C(n, m): Pascal (any mod), factorials + inverse factorials (prime mod), Lucas (huge n).
5. Stars and bars: C(n + m − 1, m − 1); non-empty C(n − 1, m − 1).
6. (a + b)ⁿ = Σ C(n, k) aᵏ bⁿ⁻ᵏ.
7. Catalan: Σ Cat(k) Cat(n−1−k) = C(2n, n)/(n + 1).
8. Stirling 2nd: S(n, k) = S(n−1, k−1) + k·S(n−1, k); labelled boxes × k!.
