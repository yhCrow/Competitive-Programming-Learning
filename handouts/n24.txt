24.1 可持久化平衡树
Copy	before	change;	one	root	per	version.
IDEA A persistent	balanced	tree ( 可持久化平衡树 ) keeps every version of a set or sequence. FHQ Treap ( 拓
展篇  第 4 章 ) is the easy one to make persistent: split and merge only touch nodes on a root path, so copy
each	node	before	changing	it. Every operation then creates O(log n) new nodes and a new root, and old
roots still describe old versions (P3835).
KEY POINT Treap priorities are random and never change, so a copied node keeps its priority and the expected shape
is unchanged. The sequence version with lazy reversal (P5055) must also copy children when pushing a
tag down, because the children may be shared with other versions.
竞 赛 拓 展 专 题  · NOI 篇  · NOI 专 题
Keep every version of a balanced tree by copying nodes in split and merge, and search hard optimisation
problems with simulated annealing plus a final hill climb.

1 #include <bits/stdc++.h>
2 using namespace std;

4 const int M = 5000005;
5 int ls[M], rs[M], val[M], pri[M], sz[M], cnt = 0, root[500005];
6 mt19937 rng(97);
7  
8 int copyNode(int x) { ++cnt; ls[cnt] = ls[x]; rs[cnt] = rs[x]; val[cnt] = val[x]; pri[cnt] = pri[x]; 
sz[cnt] = sz[x]; return cnt; }
9 int newNode(int v) { ++cnt; val[cnt] = v; pri[cnt] = rng(); sz[cnt] = 1; ls[cnt] = rs[cnt] = 0; return 
cnt; }
10 void up(int x) { sz[x] = sz[ls[x]] + sz[rs[x]] + 1; }
11 void split(int t, int k, int &a, int &b) {                 // copy every node we change
12     if (!t) { a = b = 0; return; }
13     if (val[t] <= k) { a = copyNode(t); split(rs[a], k, rs[a], b); up(a); }
14     else { b = copyNode(t); split(ls[b], k, a, ls[b]); up(b); }
15 }
16 int merge(int a, int b) {                                  // a, b are already fresh copies
17     if (!a || !b) return a | b;
18     if (pri[a] > pri[b]) { rs[a] = merge(rs[a], b); up(a); return a; }
19     ls[b] = merge(a, ls[b]); up(b); return b;
20 }
21 int kth(int t, int k) { while (true) { if (k <= sz[ls[t]]) t = ls[t]; else if (k == sz[ls[t]] + 1) 
return val[t]; else { k -= sz[ls[t]] + 1; t = rs[t]; } } }

33             if (b) b = merge(ls[b], rs[b]);                // drop one copy (b is a fresh copy)
34             r = merge(merge(a, b), c);

KEY POINT Each line "v op x" works on version v and creates version i. Random operations on random old versions,
checked against keeping a separate sorted list for every version in Python. A query creates copies too, but
they are thrown away because the version keeps the old root.
TRAP Memory: every operation copies O(log n) nodes, so size the pool for (operations × about 50) nodes. Never
modify a node that may belong to another version; always copy first (split does it here).
24.2 模拟退火
Accept	worse	moves	with	e^(−Δ/T);	cool	slowly.
IDEA Simulated	annealing ( 模拟退火 ): a randomised search for the minimum of a messy function. Keep a
current point and a temperature T. Each step moves to a random nearby point (step size proportional to T).
Accept it if it is better; if it is worse by Δ, still accept it with probability e−Δ/T. Cool T slowly (multiply by
0.99…). High T explores; low T settles.
KEY POINT It has no guarantee: use it for partial scores or when nothing exact is known, and run it several times from
random starts within the time limit. Hill	climbing is the T = 0 version (accept only improvements, shrink
the step): exact when the function is convex, as in 平衡点  (P1337), the weighted point minimising Σ
wi·distance.

annealing.cpp
1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 int n;
5 double x[1005], y[1005], w[1005];
6  
7 double energy(double px, double py) {            // the function to minimise
8     double s = 0;
9     for (int i = 0; i < n; i++) s += w[i] * sqrt((px - x[i]) * (px - x[i]) + (py - y[i]) * (py - y[i]));
10     return s;
11 }
12  
13 int main() {
14     cin >> n;
15     double cx = 0, cy = 0, W = 0;
16     for (int i = 0; i < n; i++) { cin >> x[i] >> y[i] >> w[i]; cx += x[i] * w[i]; cy += y[i] * w[i]; W 
+= w[i]; }
17     cx /= W; cy /= W;                             // start at the weighted mean
18     mt19937 rng(2024);
19     uniform_real_distribution<double> U(-1.0, 1.0), P(0.0, 1.0);
20     double cur = energy(cx, cy), bx = cx, by = cy, best = cur;
21     for (double T = 100; T > 1e-4; T *= 0.995) {  // annealing
22         double nx = cx + U(rng) * T, ny = cy + U(rng) * T, e = energy(nx, ny);
23         if (e < cur || P(rng) < exp((cur - e) / T)) { cx = nx; cy = ny; cur = e; }
24         if (cur < best) { best = cur; bx = cx; by = cy; }
25     }
26     for (double step = 1; step > 1e-8; step *= 0.5) {   // final hill climbing from the best point
27         bool moved = true;
28         while (moved) {
29             moved = false;
30             double dx[4] = {step, -step, 0, 0}, dy[4] = {0, 0, step, -step};
31             for (int k = 0; k < 4; k++) {
32                 double e = energy(bx + dx[k], by + dy[k]);
33                 if (e < best) { best = e; bx += dx[k]; by += dy[k]; moved = true; }
34             }
35         }
36     }
37     cout << fixed << setprecision(3) << bx << " " << by << "\n";
38     return 0;
39 }

KEY POINT The weighted geometric median of 8 random points, checked against Weiszfeld's iteration (an exact
convergent method) in Python. The final hill-climbing phase with halving steps polishes the annealing
result to full precision.
TRAP Tune by experiment: starting temperature on the scale of the coordinates, cooling factor 0.99–0.999, and
stop by time (clock()) rather than by a fixed count on a real judge. Always keep the best point seen, not just
the current one.

24.3 课后习题与实验
The	Luogu	problems	for	this	chapter,	a	ladder	through	them,	and	experiments	to	try	yourself.
Key	points	to	memorise
1. Persistent FHQ: copy every node split/merge changes; old roots stay valid.
2. Pool size ≈ operations × 50; push-down must also copy shared children.
3. Annealing: random step ∝ T; accept worse with e^(−Δ/T); T *= 0.99x; keep the best.
4. Convex objective ⇒ plain hill climbing with shrinking steps is exact.
