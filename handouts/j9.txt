IDEA A tree with n nodes is connected and
has exactly n − 1 edges, so there is
exactly one	simple	path between any
two nodes. Pick a root and every node
gets a parent, a depth and a subtree.
KEY POINT Store the tree as an undirected adjacency
list and pass the parent into the DFS so
it never walks back up. One DFS fills fa,
dep and sz: sz[u] = 1 + the sizes of its
children, added after the child returns.
深 入 浅 出 程 序 设 计 竞 赛  · 进 阶 篇  · 第 3 部 分  图 论
Root a tree and read off depths and sizes; find its diameter and centroid; jump to common ancestors by
doubling; and cut it into heavy chains so paths become ranges.

IDEA The diameter ( 直径 ) is the longest path in the tree. With non-negative weights: DFS from any node to the
farthest node u; then DFS from u to the farthest node v. The path u–v is a diameter.
KEY POINT Why it works: the farthest node from any start is an end of some diameter. With negative weights this
fails; use the DP instead: at each node, longest + second-longest downward path through different children.

KEY POINT Centre of the tree: the middle node(s) of a diameter, minimising the farthest distance. Do not confuse it
with the centroid below, which minimises the largest piece.
1 pieces 4, 2
2 pieces 1, 2, 3 3
4 5 6
7
IDEA The centroid ( 重心 ) is the node whose
removal leaves the largest remaining
piece as small as possible. Pieces are
the children's subtrees and the part
"above": n − sz[u]. The largest piece is
then at most n / 2.
KEY POINT The centroid also minimises the sum of
distances to all nodes (P1395 会议 ). A
tree has one centroid, or two adjacent
ones. Repeatedly splitting at centroids
gives depth O(log n), the basis of point
divide-and-conquer ( 点分治 ).

IDEA The lowest	common	ancestor LCA(u,
v) is the deepest node that is an
ancestor of both. Binary lifting ( 倍增 , 第
3 章 ): up[u][k] = the 2k-th ancestor of u,
filled by up[u][k] = up[ up[u][k−1] ]
[k−1].
KEY POINT Query: lift the deeper node to the same
depth, using the binary digits of the
difference. If they meet, done.
Otherwise, for k from high to low, jump
both while up[u][k] ≠ up[v][k]; the
answer is then up[u][0]. O(log n) per
query.

1 #include <bits/stdc++.h>
2 using namespace std;
3  
4 const int N = 500005, LOG = 20;
5 vector<int> g[N];
6 int dep[N], up[N][LOG];
7  
8 void dfs(int u, int parent) {
9     up[u][0] = parent;
10     for (int k = 1; k < LOG; k++) up[u][k] = up[up[u][k - 1]][k - 1];
11     for (int i = 0; i < int(g[u].size()); i++) {
12         int v = g[u][i];
13         if (v == parent) continue;
14         dep[v] = dep[u] + 1;
15         dfs(v, u);
16     }
17 }
18  
19 int lca(int u, int v) {
20     if (dep[u] < dep[v]) swap(u, v);
21     for (int k = LOG - 1; k >= 0; k--)               // lift u to v's depth
22         if (dep[u] - (1 << k) >= dep[v]) u = up[u][k];
23     if (u == v) return u;
24     for (int k = LOG - 1; k >= 0; k--)               // jump both, staying below the LCA
25         if (up[u][k] != up[v][k]) { u = up[u][k]; v = up[v][k]; }
26     return up[u][0];
27 }

IDEA Tree differences ( 树上差分 ): to add 1 to every node on the path s–t, mark +1 at s and t, −1 at the LCA and
−1 at its parent. Afterwards a node's value is the sum of marks in its subtree (P3128). Many paths cost
O(1) each, plus one final DFS.
KEY POINT For edges on the path (store each edge at its lower node): +1 at s and t, −2 at the LCA. Used with binary
search on the answer in 运输计划  (P2680), and per-depth counting in 天天爱跑步  (P1600).
9.4 树的重链剖分
Heavy	chains	+	a	segment	tree	over	dfn.
1 dfn 1
2 dfn 2 3 dfn 6
4 dfn 5 5 dfn 3 6 dfn 7
7 dfn 4
IDEA Heavy-light	decomposition ( 重链剖
分 ): each node's heavy	child is the
child with the largest subtree. Heavy
edges form chains (1-2-5-7, 3-6, 4).
Number the nodes in a DFS that visits
the heavy child first: every chain
becomes a block of consecutive dfn, and
every subtree too.
KEY POINT Going up from any node to the root
crosses at most log₂ n light edges,
because each light edge at least doubles
the subtree size. So any path is O(log n)
chain pieces, each a range of dfn: a
segment tree over dfn handles path and
subtree updates and queries.

9.5 课后习题与实验
The	Luogu	problems	for	this	chapter,	a	ladder	through	them,	and	experiments	to	try	yourself.
Key	points	to	memorise
1. Tree: n − 1 edges, one path between any two nodes; DFS with the parent passed in.
2. Pre-order uses the parent (depth); post-order uses the children (size, sums).
3. Diameter (w ≥ 0): farthest from any node = u; farthest from u = v.
4. Centroid: minimise max(n − sz[u], children sizes); largest piece ≤ n / 2.
5. up[u][k] = up[up[u][k−1]][k−1]; lift to equal depth, then jump while different.
6. dist(u, v) = dep[u] + dep[v] − 2·dep[LCA].
7. Path +1 on nodes: s, t +1; LCA, fa[LCA] −1; then subtree sums. Edges: LCA −2.
8. HLD: heavy son first in dfs2; chain = consecutive dfn; subtree = [dfn, dfn + sz − 1].
9. Path loop: move the node whose top is deeper; O(log n) chains per path.
