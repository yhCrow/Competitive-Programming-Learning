21.1 动态 	DP
Light	parts	in	g;	heavy	steps	as	matrices;	climb	chains.
IDEA Dynamic	DP ( 动态  DP): a tree DP must be answered again after each point change. Maximum-weight
independent set: f[u][0] = Σ max(f[v][0], f[v][1]), f[u][1] = w[u] + Σ f[v][0]. Split the children into the
heavy child s and light children, and collect the light part in g[u][0] = Σlight max(f[v][0], f[v][1]), g[u][1] =
w[u] + Σlight f[v][0]. Then the step along the heavy edge is a (max,	+)	matrix	product: (f[u][0], f[u][1]) =
[[g0, g0], [g1, −∞]] ⊗ (f[s][0], f[s][1]).
KEY POINT Keep these 2 × 2 matrices in a segment tree over HLD order ( 拓展篇  / 进阶篇  第 9 章 ). A chain's product
gives the f values of its top. A change at x updates x's matrix, then climbs: each chain top's new f changes
its parent's g (a light edge), so O(log n) chains × O(log n) segment tree = O(log² n) per change (P4719).
竞 赛 拓 展 专 题  · NOI 篇  · NOI 专 题
Re-answer a tree DP after point changes by writing each heavy-edge step as a (max, +) matrix product kept
in a segment tree over heavy-light order.

30         int v = adj[u][k]; if (v == fa[u]) continue;

32         f[u][0] += max(f[v][0], f[v][1]); f[u][1] += f[v][0];

42     if (l == r) { tr[p] = leafMat(rk[l]); return; }

48     if (x <= l && r <= y) return tr[p];

58 void change(int x, ll y) {
59     g[x][1] += y - w[x]; w[x] = y;
60     while (x) {

KEY POINT Random weights (some negative) and point changes; after each change the answer is checked against
recomputing the whole tree DP in Python. The chain's last vertex is applied to the vector (0, −∞), so the
top's f values are just the first column of the product.
TRAP Update g of the parent with the difference between the chain top's new and old f, computed before and
after the segment tree update; recomputing g from scratch would cost O(degree). The product order must
follow the chain from top to bottom.
21.2 全局平衡二叉树
Weighted	BST	per	chain;	depth	O(log	n).

4NOI 篇  第 21 章  动态  DP
IDEA A global	balanced	binary	tree ( 全局平衡二叉树 ) replaces the segment trees of heavy-light
decomposition. For each heavy chain build a binary search tree over the chain, choosing as root the vertex
that splits the chain by weight, where a vertex's weight is 1 + the sizes of its light subtrees. Light edges
hang the chain trees together into one tree of depth O(log	n) in total, not O(log² n).
KEY POINT In dynamic DP ( 第 1 节 ) every update walks from a vertex to the root and fixes one matrix per node: with
HLD that is O(log² n) segment-tree work, with the global balanced tree it is O(log n). Each node stores the
product of the matrices in its BST subtree (its own light-child matrix in the middle); a light-edge step
updates the parent chain's light matrix, exactly as in the HLD version. Used for the " 加强版 "
(strengthened) dynamic DP problem P4751, where O(log² n) is too slow.
TRAP Build by weight, not by count: choosing the middle vertex by count gives O(log² n) depth again. The tree is
static: it does not support link / cut (use LCT for that).
21.3 课后习题与实验
The	Luogu	problems	for	this	chapter,	a	ladder	through	them,	and	experiments	to	try	yourself.
Key	points	to	memorise
1. Split children: heavy son vs light; g holds the light contributions.
2. f(u) = [[g0, g0], [g1, −∞]] ⊗ f(son) in (max, +).
3. Segment tree over HLD order; chain product = top's f.
4. Change x: update matrix, climb chain tops, adjust parent g by differences; O(log² n).
5. Global balanced tree: chain BST rooted at the weighted middle; total depth O(log n).
